# 2026-AI-Hackathon
2026 AI Hackathon
## 1. 프로젝트 개요

- 프로젝트명: 배움길
- 한 줄 요약: 학교 밖 청소년의 기출 오답을 기초 연습과 재도전으로 연결하고, 봉사 멘토의 수업 준비와 활동일지 작성을 돕는 AI 멘토링 코파일럿
- 핵심 사용자: 학교밖청소년지원센터와 연결된 봉사 멘토
- 수혜자: 검정고시를 준비하는 학교 밖 청소년
- 도입 고객: 멘토링 프로그램을 운영하는 학교밖청소년지원센터와 관련 기관
- 해커톤 집중 범위: 고졸 검정고시 수학을 준비하는 학생 한 명과 멘토 한 명의 학습·회기 운영

> 학생의 배움을 잇고, 멘토의 부담을 덜다.

배움길은 학생이 틀린 문제를 다음 학습과 수업의 출발점으로 활용한다.

기출 풀이 → 오답 개념 확인 → 필요한 기초 연습 → 유사 문제 → 원래 기출 재도전

이 과정에서 쌓인 기록을 멘토에게 제공하고, 다음 수업 제안과 활동일지 초안으로 연결한다. 멘토는 근거를 확인하고 학습 방향과 최종 기록을 결정한다.

## 2. 문제 정의와 기획 배경

### 핵심 문제

검정고시를 준비하는 학생이 기출 문제를 틀렸을 때, 해설을 읽거나 같은 유형을 반복하는 것만으로는 해결되지 않는 경우가 있다. 문제 자체의 개념이 어려운지, 그 아래의 계산·기초 개념에서 막혔는지 확인해야 하기 때문이다.

봉사 멘토는 이 원인을 살피고, 필요한 설명과 연습 문제를 준비하고, 수업이 끝난 뒤 활동 서류까지 작성한다. 각 과정이 별도로 이루어지면 같은 정보를 반복해서 찾고 정리해야 한다.

배움길은 기출 오답을 보충 학습으로 연결하고, 그 기록을 멘토의 수업과 행정 업무에 이어서 활용하는 과정을 지원한다.

### 배경 및 현황

2025 학교 밖 청소년 실태조사 관련 보도에 따르면, 조사 참여자 2,811명 중 고등학교 시기에 학업을 중단한 비율은 67.2%였고, 학교를 그만둘 당시 검정고시 준비를 계획한 비율은 70.7%였다. 향후 진로를 결정하지 못했다는 응답도 31.4%였다.

이 조사는 학교밖청소년지원센터·대안교육기관 등을 이용하는 청소년을 대상으로 했으므로, 수치를 학교 밖 청소년 전체의 특성으로 일반화하지 않는다. 검정고시 학습 지원과 진로 탐색의 필요성을 보여 주는 배경 자료로 활용한다.

### 멘토링 경험에서 출발한 기획

본 기획은 기획자의 실제 멘토링 경험에서 출발한다. 학생에게 맞는 수업을 준비하고 활동 내용을 기록하는 과정에서 생기는 부담을 바탕으로, 검정고시 학습 멘토링에 필요한 지원을 구체화한다.

현장 경험으로 확인한 사실은 해당 기관과 프로그램의 범위에 한정해 설명한다. 활동기관·프로그램·사용 양식을 확인해 근거로 정리하며, 꿈여울의 학과 소개·진로 멘토링 공고는 꿈드림의 검정고시 학습 멘토링과 구분한다.

### 기존 방식 대비 기대되는 변화

아래는 배움길이 지원하려는 업무 흐름이다. 기관마다 운영 방식이 다를 수 있으며, 기대 효과는 실제 사용으로 검증한다.

| 업무 | 기존 방식에서 멘토가 하는 일 | 배움길을 통해 기대하는 변화 |
| --- | --- | --- |
| 오답 원인 확인 | 학생의 풀이를 보며 어느 단계에서 막혔는지 질문 | 관련 개념과 확인 문항을 참고해 살펴볼 범위를 좁힘 |
| 보충 문제 준비 | 학생 수준에 맞는 문제를 찾거나 직접 변형 | 검수된 문제 틀을 활용해 기초·유사 문제 준비 부담 완화 |
| 학습 결과 확인 | 설명 후 새 문제를 주고 이해 여부를 확인 | 기초 연습·유사 문제·재도전 결과를 함께 확인 |
| 다음 수업 준비 | 이전 수업을 떠올리거나 기록을 찾아 수업 구성 | 응답·메모에 근거한 AI 제안으로 준비 부담 완화 |
| 활동일지 작성 | 학습 내용과 학생 반응을 수업 후 별도로 정리 | 학습 결과와 관찰 메모로 만든 초안을 검토·수정 |
| 월별 대장 정리 | 회기별 내용을 모아 다시 입력 | 확정한 일지를 자동 합산해 반복 입력 감소 |
| 다음 회기 연결 | 이전 기록에서 진행 상황과 남은 과제 파악 | 학습 결과와 메모를 함께 확인해 이어서 준비 |

배움길은 멘토가 문제와 기록을 찾고 정리하는 시간을 줄여, 학생의 풀이를 듣고 설명하며 관계를 이어 가는 데 시간을 더 쓸 수 있도록 돕는다.

## 3. 목표 대상 및 페르소나

### 목표 대상

- 멘토: 센터와 연결되어 검정고시 과목을 가르치는 대학생 등 봉사 멘토
- 멘티: 검정고시를 준비하며 기초 개념 확인과 학습 순서 안내가 필요한 학교 밖 청소년
- 센터 담당자: 멘토링 일정, 활동 서류, 학생 기록과 인수인계를 관리하는 실무자

해커톤에서는 선별한 수학 기출과 일부 기초 개념을 연결한다. 검정고시 전 과목이나 전체 수학 범위를 지원한다고 주장하지 않는다.

### 가상 페르소나

멘토 · 김멘토, 22세

대학생 봉사 멘토로 온라인 수학 수업을 진행한다. 학생이 방정식 문제를 틀리면 방정식 개념 때문인지, 부호 계산 때문인지부터 확인한다. 필요한 보충 문제를 준비하고, 수업 후 활동일지와 월별 대장을 정리한다.

학생이 막힌 부분을 살펴볼 자료와 검수된 연습 문제, 다음 수업에 활용할 기록이 필요하다.

멘티 · 하늘, 17세·가명

학교를 그만두고 고졸 검정고시를 준비한다. 간호 분야에 관심이 있지만 진로를 확정하지는 않았다. 기출 해설을 보면 이해한 것 같지만, 숫자가 달라진 문제를 혼자 풀 때 다시 막힌다.

어느 단계에서 어려움이 생겼는지 확인하고, 필요한 기초부터 연습해 원래 문제에 다시 도전하고 싶다.

## 4. 해결 방법 및 핵심 기능

### 전체 서비스 흐름

학생의 기출 풀이와 보충 학습 → 멘토의 기록 확인·수업 준비 → 수업 → 활동일지 확정 → 다음 회기

기출·연습 결과와 멘토의 관찰 메모를 같은 학습 기록으로 연결한다. 학생은 멘토가 지정한 문제를 수업 중 또는 수업 사이에 풀고, 멘토는 그 결과를 다음 수업에 활용한다.

### 기능 1. 기출 연계 오답 보완 학습

#### ① 기출 풀이

멘티는 멘토가 지정하거나 지원 범위 안에서 선택한 기출 문제를 푼다.

- 원문 출처와 연도·회차·과목·문항 번호를 표시한다.
- 정답 여부와 선택한 답, 풀이 시간, 힌트 사용 여부 등을 기록한다.
- 문항에는 필요한 개념과 선수 개념을 연결한다.
- 복합 문항은 여러 개념이 필요할 수 있음을 반영한다.

#### ② 오답 개념 확인

오답이 나오면 관련 개념을 확인하는 짧은 문항이나 질문을 제시한다.

- 틀린 답 하나만으로 오개념을 확정하지 않는다.
- 문제에 연결된 개념 중 무엇을 추가로 확인할지 정한다.
- 필요하면 멘토가 풀이 과정을 듣고 확인 대상을 수정한다.

예를 들어 방정식 문제를 틀렸다면 등식의 성질, 부호 계산, 나눗셈 중 어느 부분을 먼저 확인할지 살펴본다.

#### ③ 필요한 기초 연습

확인 결과에 따라 더 작은 단위의 기초 문제를 제공한다.

- 학생이 막힌 단계에 맞춰 문제를 제시한다.
- 필요한 경우 첫 단계 힌트나 예시를 제공한다.
- 독립적으로 푼 결과와 도움을 받아 푼 결과를 구분한다.
- 멘토가 연습량과 진행 순서를 조정할 수 있게 한다.

#### ④ 유사 문제

기초 연습 후 같은 핵심 개념을 적용하는 새로운 문제를 제공한다.

- 해커톤에서는 검수된 문항 틀에서 숫자 등을 바꾸는 방식으로 시작한다.
- 정답 계산과 문항 조건 검사를 코드로 처리한다.
- 공식 기출과 자체 제작한 연습 문제를 화면에서 구분한다.
- AI가 자유롭게 만든 새 문항은 검수 후 사용한다.

#### ⑤ 원래 기출 재도전

보충 학습 후 처음 틀린 기출 문제에 다시 도전한다.

- 처음 응답과 재도전 결과를 함께 기록한다.
- 힌트와 멘토 도움의 사용 여부를 남긴다.
- 정답을 본 문제를 다시 맞힌 것만으로 숙달을 확정하지 않는다.
- 별도의 새 확인 문제에서도 적용할 수 있는지 살펴본다.

이 기능의 목적은 오답 수를 줄이는 데 더해, 어떤 보충 학습을 거쳐 다시 풀 수 있게 되었는지를 학생과 멘토가 함께 확인하는 것이다.

### 기능 2. 학습 근거가 보이는 멘토 대시보드

멘토는 수업 전에 다음 정보를 함께 확인한다.

| 정보 | 활용 목적 |
| --- | --- |
| 최초 기출 응답 | 학생이 처음 막힌 문제 파악 |
| 개념 확인 결과 | 우선 살펴볼 기초 개념 확인 |
| 기초·유사 문제 결과 | 보충 연습 후 적용 여부 확인 |
| 원래 기출 재도전 결과 | 이전 시도와 변화 비교 |
| 힌트·도움 사용 기록 | 독립 수행과 도움을 받은 수행 구분 |
| 이전 회기 메모 | 학생의 풀이 과정과 수업 맥락 파악 |

직접 응답으로 확인한 결과와 선수 관계를 통해 추정한 결과를 구분한다. 자가 설문과 실제 응답의 차이도 관찰 정보로 제공하며, 성격이나 태도 평가로 단정하지 않는다.

풀이 시간은 참고 정보로 제공한다. 기록 사실을 사전에 안내하고, 시간만으로 찍기·집중력·성실성을 판단하지 않는다.

### 기능 3. 학생 기록에 근거한 AI 수업 준비

AI는 기출 오답, 보충 연습, 재도전 결과와 멘토 메모를 바탕으로 다음 수업을 제안한다.

| 제공 내용 | 설명 |
| --- | --- |
| 우선 확인할 개념 | 다음 수업의 시작점으로 제안하는 개념 |
| 추천 근거 | 관련 문항 응답, 연습 결과, 도움 사용 기록, 메모 |
| 오개념 후보 | 풀이 과정에서 확인할 필요가 있는 가능성 |
| 설명 방법 | 예시, 시각화, 단계별 질문 |
| 수업용 문제 | 지원하는 문제은행·문항 틀에서 선택한 연습 문제 |
| 불확실한 부분 | 추가 질문이나 멘토 확인이 필요한 내용 |

예를 들어 기초 계산은 해결했지만 새로운 방정식 문제에서 다시 막혔다면, AI는 방정식 풀이 단계의 설명을 우선 제안하고 근거가 된 응답을 보여 준다.

자료가 부족하면 확인 질문을 제안한다. 멘토는 수업안과 문제를 수정하거나 다른 개념을 선택할 수 있다.

### 기능 4. 초기 진단과 배움길 로드맵

첫 사용 시 자가 설문과 적응형 진단으로 시작점을 추정할 수 있다. 이미 기출 풀이 기록이 있다면 해당 기록을 함께 활용한다.

- 수학 개념 28개의 선수 관계 그래프를 활용한다.
- 초기 진단은 최대 10문제로 범위를 제한한다.
- 이후 오답 확인·보충 학습 문항은 초기 진단과 구분한다.
- 직접 확인한 개념, 추정한 개념, 추가 확인이 필요한 개념을 표시한다.
- 수업과 후속 응답으로 학습 상태를 보정한다.

“10문제로 28개 개념을 정확히 진단한다”는 주장은 하지 않는다.** 제한된 응답으로 수업 시작점을 추정하는 도구로 설명한다.

기존 확인 퀴즈의 ‘3문제 중 2문제 정답’은 다음 학습을 추천하는 운영 기준으로 활용한다. 이를 장기적인 숙달의 증거로 보지 않으며, 멘토가 복습과 다음 단계 진행을 조정할 수 있게 한다.

### 기능 5. 회기 기록을 활용한 활동일지·월별 대장

수업 후 멘토는 학습 결과를 확인하고 관찰 메모를 입력한다. 배움길은 제공받은 센터 양식에 맞춰 활동일지 초안을 작성한다.

- 풀이한 기출, 확인한 개념, 보충 연습과 재도전 결과를 정리한다.
- 출석 여부와 실제 활동 시간은 멘토가 확인한다.
- AI는 기록과 메모에 근거해 활동 내용·성과 문장을 작성한다.
- 참여 태도·감정·자신감 변화는 멘토가 관찰해 입력한 경우에만 반영한다.
- 멘토가 검토하고 확정한 일지만 월별 대장에 합산한다.
- 확정한 기록을 다음 회기 준비에 활용한다.

해커톤에서는 도봉구학교밖청소년지원센터에서 제공받은 양식을 기준으로 한다. 기관별 양식 추가와 파일 출력은 후속 과제로 둔다.

### 핵심 차별점

1. 오답을 보충 학습과 수업으로 연결한다

기출을 틀린 뒤 필요한 기초를 확인하고, 연습과 재도전을 거친 기록이 다음 수업의 근거가 된다.

2. 교육자의 한 회기를 중심으로 설계한다

학생 기록 확인, 설명·문제 준비, 수업 후 메모, 활동일지 확정을 하나의 흐름으로 연결한다. 실제 멘토링 경험을 출발점으로 다른 멘토와 담당자의 사용 검증을 진행한다.

3. 근거가 보이는 AI 제안을 제공한다

추천과 함께 관련 응답·도움 사용 기록·관찰 메모를 제시한다. 멘토가 불확실성을 확인하고 결정할 수 있게 한다.

4. 현장 양식과 기록의 연속성을 지원한다

실제 제공받은 양식을 출발점으로 기록을 정리하고 다음 회기에 활용한다. 실제 서비스에서는 권한을 가진 후임 멘토에게 학습 맥락을 전달하는 구조를 지향한다.

5. 교육자와 함께 배우는 환경으로 확장한다

디지털 활용이나 자기주도 학습에 지원이 필요한 학습자에게는 교육자가 도구를 활용해 수업을 제공하는 방식이 접근 장벽을 낮출 수 있다.

성인 전체의 활용 능력을 일반화하지 않고, 교육자의 지원이 필요한 학습 환경을 대상으로 적용 가능성을 검증한다. 첫 확장 후보는 성인 검정고시 지원기관과 야학이다.

6. 처리의 정확성과 교육적 판단을 구분한다

정답 비교, 검수된 문항 틀의 정답 산출, 기록 합산은 코드가 처리한다. AI는 해석과 설명을 지원한다. 진단 규칙과 문항의 교육적 타당성은 별도로 검증한다.

초기에는 기획자의 사용 점검과 소규모 현장 검증을 진행하고, 참여 인원과 조건을 함께 보고한다. 멘토 활동 유지 기간, 학습 지속, 합격률은 장기 관찰 항목으로 둔다.

## 7. 비즈니스 모델 및 단계별 확장 전략

### 기본 방향

멘티와 봉사 멘토에게 직접 비용을 받지 않는 방향을 지향한다. 기관에는 기출 연계 학습 지원, 교육자의 수업 준비, 학습 기록과 활동 서류 관리를 제공한다.

- 핵심 사용자: 봉사 멘토, 교사, 강사
- 수혜자: 기관에서 학습 지원을 받는 학습자
- 도입 검토 주체: 프로그램 운영·관리 담당자
- 비용 부담 후보: 운영기관, 지자체, 사업 위탁·지원기관, 후원 기업

실제 도입 결정자와 예산 집행 주체는 기관별로 확인한다.

### 수익 모델 가설

| 모델 | 제공 가치 | 검증할 사항 |

성인문해교육과 노인복지관 프로그램은 콘텐츠와 평가 방식의 차이가 더 크다. 공통 운영 구조의 재사용 가능성을 확인한 뒤 별도로 검증한다. 성인문해교육에도 기관이 학습자·교강사·학습현황을 관리하는 구조가 있지만, 이는 배움길의 구매 수요를 증명하는 근거는 아니다. 국가문해교육센터 운영 안내

- 자가 설문, 적응형 객관식 진단, 개념 지도
- 숫자가 바뀌는 확인 퀴즈
- 멘토 대시보드의 학습·풀이 시간 기록과 다음 학습 추천
- 활동일지 초안과 AI 문장 작성
- 확정 일지의 월별 대장 합산
- 수업 가능 시간·신청·화상 링크 관리

### 핵심 시연을 위해 추가·보완할 범위

1. 선별 기출 문제은행
    - 수학 기출 10~20문제와 핵심 유형 2~3개를 목표로 범위를 제한한다.
    - 모든 기출을 수집하기보다 개념 지도와 연결할 문항을 선별한다.
2. 오답 보완 학습 연결
    - 기출 오답에서 개념 확인, 기초 연습, 유사 문제, 재도전으로 이어지는 흐름을 구현한다.
    - 기존 문제 생성기를 활용할 수 있는 유형부터 적용한다.
3. 근거 기반 AI 수업 제안
    - 보충 학습과 재도전 결과를 읽고 설명 방법·확인 질문을 제안한다.
4. 기록과 활동일지 연결
    - 학습 단계별 결과와 멘토 메모를 초안에 반영한다.
5. 판정·표현 보완
    - 직접 확인과 추정을 구분하고, 한 번의 응답을 과도하게 일반화하지 않는다.
    - 멘토가 학습 순서를 조정하고 진로 미정으로도 시작할 수 있게 한다.

### 후속 계획으로 설명할 범위

- 전 과목·대규모 기출 문제은행
- 자유 생성 문항의 검수·배포 체계
- 실제 인증, 센터 초대, 서버 동기화와 인수인계
- 기관별 양식, HWPX·PDF 출력
- 화상회의·알림 연동
- 다른 기관·교육과정으로의 확장

## 9. 해커톤 핵심 시연

### 시연의 목표

학생이 틀린 기출 한 문제가 보충 학습과 재도전, 멘토의 다음 수업과 활동일지로 이어지는 과정을 보여 준다.

### 시연 상황

가상 멘티 하늘은 방정식 기출을 틀린다. 멘토는 방정식 개념과 기초 계산 중 무엇을 먼저 확인해야 할지 판단할 자료가 필요하다.

| 순서 | 보여 줄 장면 | 전달할 가치 |
| --- | --- | --- |
| 1. 기출 풀이 | 선별한 기출에 답하고 오답 결과 확인 | 실제 시험 문제에서 학습 시작 |
| 2. 개념 확인 | 관련 기초 문항으로 막힌 단계 확인 | 보충할 개념의 근거 확보 |
| 3. 기초 연습 | 필요한 계산·개념을 작은 단위로 연습 | 현재 어려움에 맞는 학습 제공 |
| 4. 유사 문제 | 같은 개념의 새로운 문제에 적용 | 설명 후 적용 여부 확인 |
| 5. 기출 재도전 | 원래 문제에 다시 도전 | 이전 시도와 변화 확인 |
| 6. 멘토 대시보드 | 학습 과정과 AI 수업 제안 확인 | 다음 수업 준비 지원 |
| 7. 활동일지 | 관찰 메모를 더해 초안 수정·확정 | 기록을 다음 회기로 연결 |

진단과 목표 설정은 배경 기능으로 짧게 소개한다. 일정·화상 링크는 보조 기능으로 배치한다.

실시간 시연에서 사용하는 사전 기록은 시연용 데이터임을 밝힌다. 실제 수업이 진행된 것처럼 출석·활동 시간·성과를 만들어 넣지 않는다.

### 발표에서 강조할 메시지

- 학생이 틀린 뒤 무엇을 연습할지 안내한다.
- 오답 원인은 추가 문항과 멘토 확인을 통해 살펴본다.
- 원래 기출의 재도전과 새로운 문제의 독립 수행을 구분한다.
- AI는 근거를 정리하고 수업을 제안하며, 멘토가 결정한다.
- 같은 기록을 보충 학습, 수업 준비, 활동일지에 활용한다.
- 실제 현장 경험과 기대 효과를 구분하고, 시간 절감과 학습 효과는 사용 검증으로 확인한다.
