# 맞춤형 학습 로드맵 구현·검증 기록

2026-10-24 · ver2 · 기준 커밋 e70778b

진단에서 실제로 틀리거나 모른다고 응답한 개념을 근거로, **기초 → 선수 개념 → 원래 고졸 개념**의 학습 순서를 만든다. 처음 본 고졸 문항을 도움 없이 맞힌 개념은 ‘이번 진단 통과’로 분리한다. 오답 원인을 확정하거나 학년 전체의 숙달을 보장하는 기능은 아니다.

## 선수 연결 교정

| 고졸 본 개념 | 직접 선수 개념 | 더 기초인 개념 | 연결 이유 |
|---|---|---|---|
| 다항식의 덧셈 | 일차식의 계산 | 동류항 정리 | 같은 문자·차수의 계수끼리 계산한다. 지수법칙을 덧셈의 원인으로 연결하지 않는다. |
| 인수분해 | 이차식의 인수분해 | 분배법칙과 다항식 곱셈 | 인수분해 결과를 전개해 검산한다. 지수법칙은 곱셈·거듭제곱에서 사용한다. |
| 판별식 | 제곱과 실근의 존재 | 음수의 제곱과 부호 | 완전제곱과 실수 제곱의 부호가 실근 개수 판단의 바탕이다. |
| 근과 계수의 관계 | 이차방정식의 근과 인수 | 합차의 곱과 분배법칙 | 근을 인수에서 읽고 두 근의 곱을 전개·계산한다. |
| 이차함수의 최솟값 | 꼭짓점 | 제곱의 비음수성 | 제곱항이 0이 되는 입력에서 최솟값을 찾는다. |
| 합성함수 | 일차함수의 기본 개념과 함숫값 | 문자식에 수 대입 | 안쪽 함수의 출력값을 바깥 함수에 넣는다. 기울기 계산으로 대체하지 않는다. |
| 선분의 내분 | 좌표에서 내분과 비율 | 비에 따른 전체 나누기 | 비로 나눈 길이만큼 각 좌표에서 이동한다. |
| 점과 직선 사이의 거리 | 피타고라스 정리 **및** 직선의 방정식 기본형 | 제곱의 합 계산 **및** 좌표 대입 | 분모의 길이 계산과 분자의 좌표 대입은 별개의 선수이므로 두 갈래로 확인한다. |
| 집합의 연산 | 합집합과 교집합 | 공통 원소 찾기 | 합치는 원소와 공통 원소를 구별한 다음 개수를 센다. |
| 필요조건 | 진리집합의 포함 관계 | 명제의 참·거짓과 조건 대입 | P⊂Q이면 p⇒q이며 q는 p의 필요조건, p는 q의 충분조건이다. |
| 조건 있는 경우의 수 | 중복 없는 쌍 나열 | 조건에 맞는 대상 나열 | 조건을 만족하는 쌍을 빠짐없이, 중복 없이 센다. |
| 조합 | 선택과 제외의 대응 | 조건에 맞는 대상 나열 | n개 중 n−1개 선택을 제외할 한 개 선택과 대응시킨다. |

같은 영역이라는 이유만으로 다른 쉬운 문제를 고르는 분기를 삭제했다. `fallback_question_id`는 첫 직접 선수 문항, `prerequisite_question_ids`는 복수 선수 문항, `prerequisite_concept`는 그 개념 태그다. 집합·명제 기초를 중학교 정규 단원으로 오해하지 않도록 단계는 학년 대신 선수 관계의 깊이로 표시한다.

## 데이터와 생성

- `apps/baeumgil/scripts/build-diagnostic-roadmap.mjs`: 명시적 연결과 자체 제작 46문항(23개 개념 × 2문항)의 재현 가능한 원본.
- `public/src/content/questions.json`, `concepts.json`, `review.json`, `diagnostic.json`: 교정 데이터와 개념별 해설·연습 묶음.
- `build-exam-bank.mjs`: 앱이 읽는 진단 설정 복사본과 12개 진단 원문항의 일반 보충 학습 경로를 같은 그래프로 동기화.
- 기존 전사 등록 스크립트도 마지막에 두 생성 스크립트를 실행하므로 옛 연결로 돌아가지 않는다.
- 12개 고졸 개념을 모두 확인할 기회를 주기 위해 상한은 40문항. 현재 전부 정답이면 12문항, 전부 오답/모름이면 공유 기초를 중복 출제하지 않아 37문항이다.

## 기록과 판정

진단 세션의 각 응답에 문항 ID, 영역, 개념 태그와 이름, 단계, 원래 고졸 문항 ID, 정답 여부와 모름 구분, 도움 사용, 답변 당시 재노출 여부, 응답 시각을 기록한다. 이전 로그는 삭제·재작성하지 않고 화면에서 현재 개념 정보로 보완했음을 알린다.

Step 1은 틀린 기초 개념, Step 2는 틀린 직접 선수 개념, Step 3은 틀린 고졸 본 개념이다. ‘모름’은 원인 확정 없이 추가 확인 대상으로 포함한다. 도움·재노출 정답은 별도 재확인 목록이며, 미측정은 통과로 계산하지 않는다. 한 개만 맞혀 수준 근거가 부족한 영역도 기초 취약으로 단정하지 않는다.

카드의 보충 연습은 `roadmapPractice`에 따로 저장한다. 노출 이력은 공통으로 남지만 최초 진단의 정답·티어, 기존 과제·학습 경로·회기·일지를 바꾸지 않는다. 각 문항의 **가장 최근 연습 답변**이 모두 정답일 때 묶음 연습 완료로 표시하며, 다시 틀리면 완료를 해제한다. 해설을 보거나 이미 본 문제를 푸는 연습이므로 독립 숙달 근거로 승격하지 않는다.

## 화면과 보존

멘티와 멘토 결과 및 별도 진단 화면에 같은 로드맵을 제공한다. 영역별 3열 카드는 작은 화면에서 세로로 바뀐다. 카드에서 해설, 문항 선택, 채점, 다음 연습, 전체 로드맵 이동을 지원한다. 수식에는 화면 읽기 도구용 MathML도 포함한다.

새로고침·역할 전환·과목 이동 후에도 진단과 연습 기록이 복원된다. 과거 진단은 변경된 그래프로 재실행하지 않고 저장된 응답 자체를 복원한다. 별도 진단의 연습 데이터만 손상된 경우에는 손상 원본을 보관하고 유효한 진단 결과는 유지한다. 도움 받은 답을 독립 정답으로 표시한 모순된 기록은 거부한다.

## 검증

자동 검증은 선수 참조·개념 일치·순환 방지, 전부 정답/오답/모름, 혼합·도움·재노출·미측정, 상한 종료, 복수 선수, 이전 기록 복원, 중복·늦은 제출, 연습 기록 분리, 역할·과목 이동, 기존 보충 학습 연결을 포함한다.

실제 브라우저에서는 37문항 진단 완료, 기초 카드의 두 연습 문제 채점, 원 진단 이어가기, 새로고침 복원, 모바일 가로 넘침 없음과 제목 가림 수정, 별도 진단의 연습 복원을 확인했다. 독립 코드 검토의 중요한 지적 2건(도움/독립 근거 모순, 손상된 연습 데이터 복원)과 진리집합 문항의 정의 누락을 수정했다.

교육전문가의 별도 검증이나 학생 실측 데이터에 의한 진단 정확도 검증은 아직 수행하지 않았다. 전체 400문항 중 이번 진단과 관계없는 일반 기출 경로의 재분류는 이번 변경 범위에 포함하지 않았다. 변경은 로컬 ver2 작업 트리에 있으며 커밋·푸시는 하지 않았다.
