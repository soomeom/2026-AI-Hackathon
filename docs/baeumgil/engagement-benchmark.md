# 비슷한 앱 비교와 참여 장치 판단 (2026-10-24)

최종 발표를 준비하는 고도화 단계에서 정리한 문서다. 노션 "피드백" 페이지의 세 토글(검정고시 독학 앱, 듀오링고, 열품타)을 바탕으로 했다.
남은 작업 계획은 `docs/superpowers/plans/2026-10-24-team-feedback.md`에 있다.

## 1. 고졸 검정고시 모의고사 - 검정고시 독학 문제은행 (DAYLAB)

출처: [Google Play 앱 소개](https://play.google.com/store/apps/details?id=dev.daylab.geomjeong.go). 2026-10-24에 앱 설명을 읽고 정리했으며, 앱을 직접 설치해 보지는 않았다.

### 한 줄 비교

- **그 앱:** 혼자서 많이 풀고 오래 기억하게 돕는 독학 도구다. 6과목 문제은행, 교시별 모의고사, FSRS 간격 반복 복습이 중심이다.
- **배움길:** 멘토와 함께 끊긴 수학 개념을 찾아 다시 잇는 도구다.
- 경쟁하기보다 함께 쓰면 좋은 관계다. 발표에서는 이렇게 말할 수 있다: "독학 앱은 많이 풀게 하고, 배움길은 왜 막혔는지 찾아 준다."

### 기능 비교

| 항목 | 그 앱 | 배움길 |
|---|---|---|
| 대상 | 혼자 공부하는 수험생 | 학교 밖 청소년 + 봉사 멘토 (+ 보호자) |
| 과목 | 필수 6과목 | 수학 (깊게) |
| 문제 | 자체 제작 문제은행 | 기출 기반 진단 + 검수한 보충 문제 |
| 약점 찾기 | 과목·단원별 정답률 히트맵 | 영역 × 기초·선수·고졸 진단, 틀리면 하위 개념으로 추적 |
| 판정 방식 | 정답률 | 도움 없이 확인 / 혼자 다시 확인 / 보완 필요 |
| 복습 | FSRS 간격 반복, 복습 알림 | 보충 연습 (복습 시점 예약 없음) |
| 오답 관리 | 오답 노트 자동 정리, 복습함, 메모 | 개념별 기록 |
| 실전 연습 | 교시별 모의고사 (40분, 평균 60점 합격선) | 없음 |
| 동기부여 | D-day, 연속 학습, 캘린더, 성장 리포트 | 로드맵 진행, 관계 지도 |
| 사람 연결 | 1:1 문의 | 멘토 수업 준비, 활동일지, AI 코파일럿, 보호자 공유 |
| 편의 | 글자 크기, 다크 모드, 오프라인, 기기 동기화, 이어서 풀기 | 이어서 풀기, 큰 글씨 |

### 가져오면 좋은 점 (추천 순)

1. **시험 D-day와 남은 기간에 맞춘 진도.** 쉽고 효과가 크다.
   - 진도는 "남은 보완 개념 12개 · 남은 8주 → 한 주에 2개"처럼 로드맵과 연결해 보여 준다.
   - 시험 날짜는 앱이 정하지 않고 사용자가 직접 입력한다. 교육청 공고를 확인하라는 안내를 붙인다.
2. **시험 7일 전 체크리스트.** 쉽다. 시험장 경험이 적은 학생에게 도움이 된다.
3. **다시 확인할 때가 된 개념 알려 주기.** 중간 규모다.
   - FSRS를 단순하게 줄인 방식(1일 → 3일 → 7일)으로 다시 확인할 때를 알려 준다.
   - '혼자 다시 확인' 상태를 '도움 없이 확인'으로 올리는 판정 원칙과 맞는다.
4. **오답 노트 자동 정리.** 중간 규모다. 각 문제에 "○○ 개념 때문"을 함께 보여 주면 그 앱과 차별된다.
5. **보기 지우며 풀기(소거법).** 쉽다. 멘토가 학생이 무엇을 지웠는지 보면 생각한 과정을 짐작할 수 있다.
6. **학습 캘린더.** 쉽다. 연속 일수 대신 쌓이는 숫자로 보여 준다.
7. **콘텐츠 안내 문구.** 아주 쉽다. 문제 출처, 정부 기관과 관계없음, 합격을 보장하지 않음을 적는다.

### 가져오지 않는 게 좋은 점

- **6과목 확장, 교시별 모의고사:** 문제를 만들고 검수하는 비용이 크다. 수학 개념 추적이라는 강점이 흐려진다.
- **푸시 알림, 기기 동기화, 오프라인:** 로그인과 서버 저장이 필요해 해커톤 범위를 넘는다.
- **정답률 하나로 판정:** '도움 없이 확인'이라는 차별점이 사라진다.

## 2. 듀오링고·열품타의 참여 장치

두 앱의 기능은 알려진 공개 기능을 기준으로 정리했다. 이번에 앱을 직접 설치해서 확인하지는 않았다.

### 듀오링고

| 장치 | 참여를 끌어내는 방식 | 배움길 적용 |
|---|---|---|
| 친구와 함께하는 연속 기록(불꽃) | 둘 다 해야 이어져서 서로 챙김 | 멘토·멘티가 함께하는 형태로 바꿔 적용 |
| 친구와 함께하는 주간 퀘스트 | 같은 목표를 나눠 채움 | **적용** (함께 목표의 원형) |
| 응원 보내기 | 버튼 하나로 가볍게 반응 | 함께 목표 안에 합침 |
| 매일 연속 학습일 | 끊기기 싫어서 매일 들어옴 | 적용 안 함 (불규칙한 생활에는 역효과) |
| 리그·순위 | 경쟁 | 적용 안 함 (비교가 상처가 되고, 학생 정보가 노출됨) |
| 하트 | 틀리면 줄어듦 | 적용 안 함 (틀린 답은 진단의 근거) |
| 푸시 알림 | 앱 밖에서 다시 부름 | 지금은 어려움 (서버 필요) |

### 열품타

| 장치 | 참여를 끌어내는 방식 | 배움길 적용 |
|---|---|---|
| 공부 타이머 | 공부를 시작하는 의식, 쌓인 시간이 보람 | 이번에는 뺌 (아래 판단 참고) |
| 공부 기록 달력(잔디) | 공부한 날이 쌓임 | 이번에는 뺌 |
| 그룹 '같이 공부 중' 표시 | 다른 사람을 보며 자극 | 실시간 표시는 서버가 필요해 나중에 함 |
| 하루 목표 시간 | 목표를 채우는 재미 | 함께 목표로 대신함 |
| 순위표 | 경쟁 | 적용 안 함 |
| 다른 앱 잠금 | 딴짓 차단 | 웹에서는 불가 |

## 3. 최종 판단: 무엇을 할까

처음에는 아래 네 가지를 추천했다.

1. 멘토·멘티 함께 목표 + 배움 불꽃
2. 응원 보내기
3. 공부 타이머 + 달력
4. 다시 왔을 때 반겨 주기

최종 발표 준비 시점을 기준으로 다시 따져 보면 넷을 다 하는 것은 좋지 않다.

판단 기준은 두 가지다.
- 5분 시연에서 심사위원에게 보이는가.
- 남은 시간에 확실히 끝낼 수 있는가.

| 항목 | 결정 | 이유 |
|---|---|---|
| 1. 함께 목표 + 불꽃 | **작게 한다** | "학교 밖 청소년이 어떻게 꾸준히 하나?"라는 질문에 답이 된다. 멘토 연결이라는 강점을 살린다. 다만 불꽃 개수와 연속 기록은 몇 주가 쌓여야 의미가 있고 시연에서는 가짜 기록이 필요하므로, 이번 주 목표 칸과 완료 표시만 만든다. |
| 2. 응원 보내기 | **1번에 합친다** | 따로 만들면 보호자 응원과 비슷한 기능이 둘이 된다. 목표를 채웠을 때 멘토가 응원을 남기는 정도로 넣는다. |
| 3. 타이머 + 달력 | **뺀다** | 오래 써야 숫자가 쌓여서 시연에서 보여 줄 것이 거의 없다. 정확히 재려면 멈춤 판정, 탭 이동 같은 예외 처리가 많다. 그런데 실력 판정에는 쓰지 않는 수치다. 발표에서 "다음 단계"로 소개한다. |
| 4. 다시 왔을 때 반겨 주기 | **새로 만들지 않는다** | '다음 학습' 카드와 '이어서 풀기'가 이미 같은 역할을 한다. 카드 문구만 다듬는다. |

### 우선순위

1. 피드백 수정 5건
2. AI 힌트
3. 이번 주 함께 목표 (작게, 응원 포함) — 1·2가 끝나고 시간이 남을 때
4. '다음 학습' 카드 문구 다듬기

### 발표할 때 주의

- 참여율이 오른다고 단정하지 않는다. 검증한 근거가 없다.
- "꾸준히 참여하도록 이렇게 설계했다"는 의도 수준으로 말한다.
- 경쟁과 벌 대신 '함께'와 '응원'을 택한 이유를 말한다. 학교를 떠난 경험이 있는 학생에게는 비교와 실패 표시가 역효과를 낼 수 있기 때문이다. 이 설명은 질의응답에서 설득력이 있다.
