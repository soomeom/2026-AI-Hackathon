# 주간 목표·응원·학생 성취 개선 통합 검증

2026-10-24 · ver2 · 기준 커밋 59143e9

## 반영한 동작

- 한국 시간 월~일의 연습 기록으로 개념을 주당 한 번 집계한다. 지난주 완료한 개념도 이번 주에 다시 연습 조건을 채우면 인정한다.
- 등록 보충 묶음은 이번 주 응답만으로 모든 문항을 정답 처리해야 한다. 지난주 답과 이번 주 일부 답을 합쳐 완료로 표시하지 않는다.
- AI 보충 정답과 등록 묶음 완료는 같은 개념이면 중복으로 세지 않는다. 도움 받은 정답도 참여로 인정하며 진단·숙달과는 구분한다.
- 목표 달성 전에도 멘토가 응원을 남길 수 있다. 멘티·보호자는 작성할 수 없으며 빈 문구와 200자 초과 문구는 거부한다.
- 잘못 입력했을 때 입력 영역을 열린 상태로 유지해 오류 안내를 바로 볼 수 있다.
- 학생 학습 완료와 함께하는 수업 완료를 따로 표시한다. 두 조건을 채운 경우에만 공동 완료·축하 안내를 표시한다. 아직 완료 개념이 없더라도 '학습 시작 전'으로 단정하지 않는다.
- 카드 위치는 멘토 홈, 멘티 진단 결과·학습 완료·대기 화면이다. 문제 풀이 화면과 저장 형식은 유지했다.

## 기존 기록 보존

- 기존 진단·응답·보충 연습·회기·일지·숙달 근거를 삭제하거나 덮어쓰는 마이그레이션은 없다. 기존 기록을 읽어 이번 주 참여 수만 다시 계산한다.
- 지난주 개념 복습 전후 원본 진단과 기존 응답을 비교했다. 응원 저장 전후에는 응원 목록·revision 이외의 상태가 동일함을 확인했다.
- 과거 응원 저장 형식도 유지한다. 역할 전환과 새로고침 후 이번 주 응원이 표시된다. 보호자 안내와는 별도 저장이다.

## 검증 결과

- 관련 집계·앱 통합 테스트 **31/31 통과**.
- 전체 테스트 **262/262 통과**, 실패·건너뜀 0. 최초 실행의 HTTP 테스트 12건은 샌드박스 로컬 접속 제한(EACCES)으로 실패했으며, 허용된 실행 환경에서 전체 검사를 다시 통과했다.
- 콘텐츠 검사: 출제 가능 362문항, 오류 0. 자체 제작 문항을 포함한 수이며 공식 기출 확보 수와 다르다.
- 회귀 검사: 지난주 개념의 이번 주 복습, 부분 복습 제외, 등록·AI 중복 제외, KST 주 변경, 미래·다른 학생 기록 제외, 결석·취소 회기 제외, 역할·문구 검증, 역할 전환·재로딩 후 응원·기록 유지.
- 별도 읽기 전용 코드 리뷰의 오류 문구와 0개 상태 표현 지적을 반영했고 재검토에서 추가 문제가 발견되지 않았다.
- 실제 브라우저: 0/2·0/1 상태에서 응원 저장 → 멘티 결과 표시 → 새로고침 후 유지. 빈 입력 안내가 접히지 않고 표시되는 것도 확인했다.
- 실제 브라우저: 지난주·이번 주에 같은 두 개념을 완료한 가상 기록이 2/2로 표시되고, 참여 수업이 없는 상태에서 학생 완료·수업 대기를 구분했다. 기존 공동 완료 가상 기록의 두 완료 표시·축하 안내도 확인했다.
- 큰글씨: 데스크톱 1280px 화면에서 본문 기준 20px, 문서 폭 1265px. 390px iframe 화면에서 기준 20px, 표시 영역·문서 폭 모두 375px로 가로 넘침이 없었다. 모바일은 실제 기기가 아닌 브라우저 내 동일 앱의 좁은 화면 검증이다.
- 다른 관련 Codex 세션은 대기 상태이고 시작 시 작업 트리는 깨끗했다. 작업 중 추가된 외부 변경 없이 요청 범위의 파일만 수정했다.
- 기존 팀원용 서버의 상태 확인과 화면 파일 요청 모두 HTTP 200이며, 개선된 목표 화면을 제공함을 확인했다. 변경 공백 검사도 통과했다. 검증용 임시 파일·서버는 정리했다.
