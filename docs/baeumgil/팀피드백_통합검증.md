문제 풀이 중에는 주간 목표 카드를 추가하지 않아 기존 풀이 화면을 유지한다. 6번 완료 도장은 팀원 안을 기다리는 보류 상태, 8번 손글씨 사진 분석은 미정 상태로 유지한다.

## 힌트와 기록 기준

- AI는 검토된 질문 후보의 ID를 고른다. 자유 문장·미등록 ID·여분 필드는 허용하지 않는다. 정답이 포함될 수 있는 해설 첫 줄을 기본 힌트로 사용하지 않는다.
- 서버는 문항 출처를 다시 검증하고, 모델 입력에서 정답·해설·생성 원본 spec를 제외한다. 서버 최대 5초, 브라우저 최대 5.5초 뒤에는 기본 질문으로 이어진다.
- 힌트 사용 이력은 `hintUsage`에 별도로 저장하고 정답 제출 시 `helpUsed`를 강제로 반영한다. 체크 해제·새로고침으로 도움 사용을 지울 수 없다.
- 화면·역할 이동 또는 답 제출 뒤 도착한 응답은 버린다. 기존 방식과 새 방식의 라운드 ID를 모두 복원한다.
- 지정 취소는 기록 삭제가 아니다. 응답·근거·회기·일지는 보존하고, 취소한 경로만 다음 학습과 진행 수에서 제외한다. 다시 지정하면 새 과제·경로를 만든다.
- 주간 목표는 한국 시간 월~일로 집계한다. 등록 보충 묶음의 첫 완료 또는 AI 보충 정답을 개념별로 한 번 센다. 지난주에 이미 완료한 개념의 반복 성공을 이번 주 새 완료로 세지 않는다. 수업은 해당 주의 참여 회기만 세며 결석·취소·미래 날짜는 제외한다.
- 도움 받은 연습도 주간 참여에 포함한다. 목표 완료는 진단·독립 숙달 판정을 바꾸지 않는다. 목표 응원은 보호자 전용 공유 안내와 별도로 저장한다.

## 검증 결과

- 전체 테스트 **257/257 통과**, 실패·건너뜀 0.
- 콘텐츠 검사: 출제 가능 362문항, 오류 0. 자체 제작을 포함한 수이며 공식 기출 확보 수와 다르다.
- 변경 파일 공백 검사 통과.
- 실제 앱 경로: 취소 확인 → 새 과제 재지정 → 새로고침, 멘토 읽기 전용, 별도 로드맵 메뉴의 힌트 → 도움 받은 정답 → 기록 복원 확인.
- 과거 `activeRole: mentee` 저장본에서도 현재 멘토 화면 역할로 응원 저장 → 멘티 전환 → 새로고침을 확인했다.
- 브라우저 가상 기록: 원래 지정 학습 응답 1건·진단 응답 37건을 유지하면서 취소·재지정·힌트·목표 응원을 검증했다. 팀원용 서버의 저장 기록을 초기화하지 않았다.
- 팝업 1440×700: 내부 높이 652, 스크롤 높이 822, 마지막 영역 접근. 390×700: 내부 높이 531, 스크롤 높이 1249, 마지막 영역 접근. 두 경우 모두 배경 페이지 이동 0.
- 큰글씨 모바일 목표 카드: 본문 20px, 표시 폭과 문서 폭 모두 375px로 가로 넘침 없음.
- 팀원용 서버 `/api/health` 200 및 실제 AI 힌트 요청 200, 등록된 `like-1-1` 응답 확인. 실제 브라우저에서 AI 선택과 기본 힌트 대체 경로를 모두 확인했다.
- 다른 관련 채팅의 코드 작업 충돌은 확인되지 않았다. 진행 중 계획서에 추가된 9번도 반영했으며, 다른 문서 변경은 유지했다.
