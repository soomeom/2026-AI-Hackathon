## 반영 내용

- 한국 시간 최근 7일 날짜별 응답 막대그래프와 수치·글 요약. 모름을 포함하고 종류별 상세를 별도로 제공한다.
- 기록 없는 날을 학습하지 않은 날로 판단하지 않는다. 날짜가 없는 과거 응답은 그래프에서 빼고 건수를 안내한다.
- 개념의 최근 응답을 혼자 해결한 근거 / 연습에서 해결 / 함께 확인할 개념으로 구분한다. 독립 수행과 연습 정답을 합쳐 숙달로 계산하지 않는다.
- 실제 의존관계에 따른 기초→선수→고졸 개념 줄기를 표시한다. 아직 확인하지 않은 약점을 임의로 추가하지 않는다.
- 보호자 렌더에는 학습 변경 함수를 전달하지 않고, 초기화 버튼과 명령도 차단한다. 다른 학생의 응답과 내부 일지·메모·검토 전 AI 제안은 요약에 포함하지 않는다.
- 공유 안내 필드는 선택적 검증을 추가해 이전 저장본을 그대로 유지하며 손상본은 원문 복구 대상으로 둔다.
- 표시 설정은 baeumgil:display:v1에 저장한다. 학습 저장 키와 분리되어 새로고침·역할 이동 후 유지된다. 글씨 전환 시 DOM을 교체하지 않는다.
