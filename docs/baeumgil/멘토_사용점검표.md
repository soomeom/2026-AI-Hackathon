# 배움길 멘토 사용 점검표

목적: 팀원 멘토 1명이 직접 사용하며 이해하기 어렵거나 수업 준비에 부족한 부분을 찾는다. 학습 효과 평가나 학생 5명 대상 제품 검증으로 해석하지 않는다.

현재 확인된 사실은 ‘팀원 1명이 학생 5명에게 수학을 멘토링한 경험이 있다’까지다. 대상·기간·방식은 아직 확인하지 않았다.

## 준비

- 주소: http://172.31.149.245:4173/
- 평소 학습 기록을 유지한다. 새로운 예시가 필요하면 별도 브라우저 프로필 또는 시크릿 창에서 가명 데이터를 사용한다.
- 기록은 브라우저별로 저장된다. 아래 역할 변경은 같은 브라우저에서 한다.
- 진행자가 방법을 설명하기 전에 멘토가 스스로 찾아보게 한다. 막히면 멈춘 위치와 도와준 내용을 적는다.
- 학생의 실제 이름·연락처·개인사나 원본 학생 기록을 입력하지 않는다.

## 직접 해 볼 일 (약 5~10분)

| 순서 | 해 볼 일 | 관찰한 내용 |
|---|---|---|
| 1 | 멘티로 수학에 들어가 첫 수준 확인을 시작한다. 첫 세 문항에서 ‘모름’을 선택한 뒤 여기까지 하고 멘토에게 넘긴다. | 결과에서 지금 확인한 범위를 어떻게 이해했나? |
| 2 | 추천 개념의 보충 연습을 열고 한 문제를 푼다. | AI 문항 또는 기존 대체 문항의 구분을 알아봤나? 기다릴 때 무엇을 했나? |
| 3 | 새로고침 후 답과 해설이 남는지 확인한다. | 문항·선택·결과 중 달라진 것이 있나? |
| 4 | 같은 브라우저에서 멘토로 역할을 바꿔 연습 기록을 찾는다. | 처음 찾은 메뉴, 헤맨 위치, 도움 요청을 적는다. |
| 5 | 다음 수업에서 무엇부터 확인할지 정하고 수업 준비로 이동한다. | 어떤 기록을 근거로 어떤 개념을 골랐나? 부족한 정보는 무엇인가? |

AI 생성 실패로 기존 문제를 풀었다면 AI 연습 기록으로 표시되지 않는 것이 정상이다. 그때 본 안내와 다음에 할 수 있었던 일을 기록한다. 성공 화면을 만들려고 실패 경험을 지우거나 반복 횟수를 숨기지 않는다.

## 사용 후 질문

1. 평소 첫 수업에서 학생 수준과 시작점을 어떻게 정했나요?
2. 방금 본 기록 중 다음 수업을 준비할 때 쓸 정보는 무엇이었나요? 실제 화면의 한 사례로 말해 주세요.
3. 이해하기 어려웠거나 예상과 다르게 동작한 곳은 어디였나요?
4. 다음 수업을 정하는 데 더 필요했던 정보는 무엇인가요?
5. 실제 수업에서 쓰기 전에 가장 먼저 고쳐야 할 한 가지는 무엇인가요?

- 성공한 작업 / 막힌 작업 / 진행자가 도와준 내용:

- 다음 수업에서 확인하기로 한 개념과 근거:
- 생성 대기·실패·대체를 경험한 횟수와 당시 반응:
- 후속 수정 / 재확인 결과:

이 문서는 점검 절차이며 사용 평가 결과가 아니다. 실제 응답을 확보한 뒤에만 결과를 채운다. 팀 내부 1명의 의견은 내부 사용성 피드백으로 보고한다.
