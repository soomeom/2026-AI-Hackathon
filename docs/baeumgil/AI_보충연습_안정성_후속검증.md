# AI 보충 연습 안정성 후속 검증

작성일: 2026-10-24 / 기준: ver2 4af883c 이후 / 발표 자료 변경 없음

## 실제 반영한 변경

1. **동류항 생성 예제의 모순 수정**: 출력 스키마는 두 문자항의 합을 요구했지만 예제는 차를 보여 주고 있었다. 예제를 합으로 바꾸고 계산한 정답도 함께 교정했다.
2. **간결한 JSON 응답 지시**: 모델이 들여쓰기·줄바꿈·설명을 생성하지 않도록 했다. 동일 사양을 보내며 실제 응답 길이가 약 1,540자에서 817자로 줄어드는 것을 관찰했다.
3. **회귀 검사 추가**: 두 개념의 프롬프트 예제를 출력 스키마 및 기존 수학 검사기에 모두 통과시킨다. 수정 전 동류항 예제의 불일치가 재현됐고 수정 후 통과했다.

문항 정답·선택지 동치·개념·범위 검사는 그대로다. 서버 5초/브라우저 6초, 한 요청 한 번 호출, 실패 시 기존 문제 제공을 유지한다. 공개 API·저장 스키마·validatorVersion·기존 진단과 기출 지표를 바꾸지 않았다.

## 실측과 해석

| 점검 형태 | 동류항 통과 | 일차식 통과 | 합계 | 처리 |
|---|---:|---:|---:|---|
| 이전 구현의 기록 | 2/5 | 5/5 | 7/10 | 이전 검증 자료 유지 |
| 예제 수정 + 간결한 JSON | 5/5 | 2/5 | 7/10 | 현재 반영한 형태 |
| 배열 전송 실험 | 3/5 | 2/5 | 5/10 | 정식 반영하지 않음 |
| 배열 전송 안내 통일 실험 | 0/5 | 3/5 | 3/10 | 정식 반영하지 않음 |

가상 응답으로 점검했으며, 생성 결과가 아니라 요청별 성공·실패를 모두 기록했다. 원자료는 [반영한 형태의 측정](ai-practice-stability-interim-check.json), [배열 전송 실험](ai-practice-stability-compact-interim-check.json), [추가 실험](ai-practice-stability-discarded-compact-check.json)에 있다. 이전 기록은 [초기 측정](ai-practice-live-check.json)에 있다.

**전체 생성 성공률이 개선됐다고 입증하지 못했다.** 작은 표본에서 동류항 통과가 늘었지만 공급자 대기 시간이 요청별로 크게 달랐다. 간결한 JSON 단계와 배열 전송 단계의 실패는 모두 시간 초과였다. 검사 기준을 완화하거나 늦은 응답을 성공으로 계산하지 않았다.

제품 제한을 늘리지 않는 별도 지연 진단에서는 응답 헤더를 받기까지 5.368초, 추론 수준을 minimal로 명시한 다른 요청은 8.017초가 걸렸다. 반환된 문항 자체는 수학 검사를 통과했다. 추론 설정 변경이 지연을 해결한다는 근거가 없어 제품 설정에 적용하지 않았다.

배열 전송은 응답을 약 395자로 줄이고 기존 AST로 정확히 복원할 수 있었다. 하지만 5초 내 생성 성공률 개선을 확인하지 못해 새 변환기와 스키마 변경을 제품에서 제거했다. 추가 복잡성을 반영하지 않고 확인된 예제 오류 수정만 유지한다.

## 통합 검사

- 전체 테스트 **225/225 통과**.
- 콘텐츠 검사: 출제 가능 문항 **362**, 오류 **0**.
- 기존 공급자·HTTP·기록 복원·역할 변경·기존 문제 대체 검사 통과.
- 브라우저에서 수정 전에 생성한 AI 문제 2건과 답변이 멘토 화면에 그대로 표시됨을 확인했다.
- 코드 검토에서 실험한 변환 경로의 중요 결함은 발견하지 못했다. 공급자에서 배열 응답을 직접 검사하는 보강도 수행했으나 실험 방식 자체를 최종 반영하지 않았다.
- 사용자 요청으로 생성 안내 수정·회귀 테스트·검증 기록을 ver2에 커밋한다. 원격 푸시는 이번 요청에 포함되지 않는다.

## 실제 멘토 사용 점검

[멘토 사용 점검표](멘토_사용점검표.md)를 준비하고 사용자에게 실제 의견을 요청했다. 답변 전이므로 **실제 사용 평가는 미실시/의견 미확보**다. 팀원의 수학 멘토링 경험(학생 5명)을 제품 사용자 5명 검증으로 해석하지 않는다.

## 남은 한계

- 외부 생성 응답의 5초 이내 완료는 보장할 수 없다. 현재는 생성이 늦으면 기존 문제로 학습을 이어간다.
- 외부 지연의 해결과 교육적 효과를 검증했다고 설명하지 않는다.
- 실제 멘토가 직접 사용한 후 유용한 정보·막힌 위치·필요한 수정 사항을 기록해야 한다.
