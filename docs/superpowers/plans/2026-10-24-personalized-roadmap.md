# 진단 기록 기반 맞춤형 학습 로드맵

사용자가 요청한 네 가지 요건을 구현한다. 기존 ver2 기록과 역할/과목 이동을 보존한다. 이 요청은 구현까지 승인되어 있으며 추가 설계 승인 없이 진행한다.

## 결정

- 같은 영역에서 임의로 쉬운 문제를 선택하는 분기를 없앤다. 각 고졸 문항 → 직접 선수 개념 → 기초 개념을 명시하고 검증한다.
- 단계는 진단 경로의 깊이를 뜻한다. 집합·명제처럼 중학교 정규 단원이 아닌 기초도 있으므로 학년으로 단정하지 않고 `기초 / 연결 개념 / 고졸 핵심`으로 표시한다.
- 12개 고졸 개념 모두 확인할 기회를 주며 하위 확인까지 최대 40문항이다. 같은 기초를 이미 확인했다면 재출제하지 않는다.
- 오답과 모름은 학습 필요의 근거로 보존하되 원인을 확정하지 않는다. 도움·재노출 정답은 재확인 대상, 독립 정답만 이번 진단 통과이다. 미측정은 통과 처리하지 않는다.
- 최초 진단 로그는 바꾸지 않는다. 보충 연습은 별도 기록으로 남기며 연습 완료가 진단 티어/숙달 근거를 소급 변경하지 않는다.
- 카드의 순서는 기초 → 선수 → 고졸이다. 카드는 모두 열 수 있고 미완료 선수 카드를 안내한다. 완료는 해당 묶음의 모든 문항을 맞힌 상태이며 재노출 연습임을 밝힌다.
- 기존 저장본은 지우지 않는다. 메타데이터 없는 이전 로그는 현재 카탈로그로 보완해 표시하고 이전 연결의 한계를 명시한다.

## 작업과 검증

1. 데이터: 12개 고졸 문항별 연결 교정, 기초 자체 제작 문항·학습 묶음 추가, 생성 스크립트에서 재현. 네 가지 지정 연결/깊이/개념 일치/누락·순환 거부 테스트.
2. 엔진: 시점·영역·문항·개념·단계·원 문항·정오 로그, 임의 하향 제거, 진단 기반 3단계 계획. 전부 오답/정답/모름/혼합/도움/상한/이전 로그 테스트.
3. 연습: 로드맵 카드의 해설·문항·채점, 별도 영속 기록 및 노출 기록, 중복·잘못된 카드/문항 거부. 기존 진단/과제/회기/일지 보존 테스트.
4. UI: 멘티와 멘토 결과, 별도 진단 화면에도 동일 로드맵. 작은 화면, 키보드 접근, 재진입 확인.
5. 전체 테스트·콘텐츠 검사·실제 브라우저 확인·독립 검토 후 중요한 결함 수정. 커밋/푸시는 별도 요청 시 수행.

## 검토 초점

잘못된 선수 관계가 재생성으로 돌아오지 않는지, 미측정을 숙달로 오해하지 않는지, 연습 기록이 진단 결과를 오염시키지 않는지, 새로고침/역할 전환/과목 이동에도 데이터가 유지되는지 확인한다.

## 진행 기록

- 기준 HEAD e70778b, ver2 작업 트리 깨끗함. 같은 저장소의 다른 작업 세션 idle 확인.
- 사전 점검: 현재 진단 엔진과 로드맵이 같은 questions/diagnostic 설정을 소비함. exam-bank에 설정 복사본이 있으므로 생성 시 동기화한다.

- 데이터/엔진 검증 통과. 복수의 직접 선수가 필요한 거리 개념은 두 갈래로 확인하므로 상한을 40문항으로 조정. 전체 오답 시 실제 출제는 공유 기초를 제외한 37문항.

- Task 1~4 complete: 46개 자체 제작 문항(23개 개념, 각 2문항), 명시적 선수 그래프, 구조화 로그, 3단계 로드맵, 별도 연습 기록 및 양쪽 진단 UI 연결.
- 최종 독립 검토: 도움 사용과 독립 수행의 모순 거부, 손상된 별도 연습 기록을 원본 보관하며 진단 복원(회귀 테스트 RED→GREEN). 문항의 진리집합 정의 누락도 보완.
- 추가 검증 발견: 1개 독립 정답만 있는 영역은 기초 취약으로 단정하지 않고 판단 보류. 수식 MathML 접근성, 모바일 제목 가림 수정. 연습 중 다시 틀린 문항은 완료 표시를 해제하되 원 진단은 유지.
- 검토 제외 항목 판단: 브라우저 화면은 작성자가 직접 확인. 교육전문가 검증/실측 정확도는 주장하지 않음. 전체 400개 기출의 비진단 경로 재분류는 이번 범위 밖이며, 12개 진단 원문항의 기존 보충 경로는 같은 선수 그래프와 동기화함.
- 최종 검증: 전체 182/182 통과, 콘텐츠 검사 통과(일반 출제 가능 362문항), 생성 파일 5개 재생성 시 내용 동일. 실제 브라우저 37문항 완료 및 연습/복원/모바일 점검 완료.
