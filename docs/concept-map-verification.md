# 개념 관계 지도 구현·검증 (2026-10-24)

## 사용 경로

- 멘티: 입장 → 수학 → 상단 **로드맵**.
- 멘토: 입장 → 수학 → 멘토 메뉴의 **로드맵**.
- 추천 경로, 영역별, 전체 보기로 전환할 수 있다. 개념을 선택하면 직접 선수 관계·진단 응답 근거가 표시된다.
- 진단 완료 또는 중간 종료 후에는 확인한 개념의 **해설과 보충 문제 풀기**로 기존 연습을 연다. 단계별 카드 보기와 기존 진단 결과 화면도 유지한다.
- 진단 전·진행 중에도 지도는 볼 수 있으나 보충 문제·풀이를 먼저 노출하지 않는다. 미확인 개념을 통과나 약점으로 추정하지 않는다.

## 데이터 보존

- 저장 키·스키마와 기존 진단, 학습, 회기, 확정 일지는 변경하지 않는다.
- 지도·필터 탐색은 UI 상태만 변경한다. 실제 문제를 여는 시점부터 기존 보충 학습 저장·노출 추적 경로를 사용한다.
- 최초 진단 통과와 보충 연습 완료를 별도로 표시한다. 지도 표시는 현재 검수된 직접 선수 관계를 사용한다.
- 새로고침 후 메뉴 위치는 기존 기본 화면으로 돌아가지만, 로드맵 메뉴를 다시 누르면 진행 중 연습·답안이 복원된다.
- 일반 학습에서 로드맵으로 이동하면 풀이 시간 측정을 멈춘다. 회기 입력을 저장하지 않고 메뉴를 나가면 기존 이탈 확인을 적용한다.

## 적용 범위 판단

- 모바일은 3열 축소 대신 세로 노드와 상세의 ‘먼저/다음 개념’ 관계 버튼을 사용한다. 좁은 화면에서 글자와 조작 대상을 유지하기 위한 선택이다.
- 지도는 교과 전체가 아니라 현재 초기 진단에 연결된 37개 개념을 표시한다. 기존 선수 관계의 교육적 타당성 자체를 이번 UI 변경에서 새로 입증하지는 않는다.
- 라이브 AI 코드는 변경하지 않았으며 이번 검증에는 외부 AI 재호출을 포함하지 않았다.
- 커밋·푸시는 아직 하지 않았다.
