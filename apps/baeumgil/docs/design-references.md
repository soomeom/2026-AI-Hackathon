# 배움길 디자인 레퍼런스

- 작성일: 2026-10-24
- 대상: PM·FE 및 배움길 ver2 통합 개발 담당자
- 목적: 멘티 학습 화면과 멘토 관리 화면을 설계할 때 참고할 제품·화면·디자인 방향을 공유한다.
- 기준: 공식 제품 소개와 도움말을 바탕으로 정리했다. 아래의 배움길 적용 방향은 팀을 위한 제안이며, 기능 범위와 우선순위는 기존 PRD·개발 계획을 따른다.

## 1. 우선 추천하는 조합

**멘티 화면은 Brilliant, 멘토 화면은 칸아카데미를 우선 참고한다.**

문제풀이와 멘토 관리라는 두 핵심 경험을 각각 살펴본 뒤, Quizlet의 학습 카드와 Classkick의 풀이 확인·피드백 화면을 보충해서 참고한다. 버튼·글자·상태 표현은 배움길 전체에서 일관되게 정리한다.

## 2. 제품별 레퍼런스

| 레퍼런스 | 디자인에서 살펴볼 부분 | 배움길 적용 화면 | 우선순위 |
| --- | --- | --- | --- |
| [Brilliant](https://brilliant.org/) | 수학 개념의 시각적 표현, 설명과 연습의 연결, 학습 진행 표시 | 문제풀이·기초 연습·배움길 로드맵 | 최우선 |
| [칸아카데미 — 새 교실 화면 소개](https://blog.khanacademy.org/meet-the-new-khan-academy-classroom-experience/) | 교사 대시보드의 정보 우선순위, 학생·과제·보고서 간 이동. 소개 페이지의 **Watch demo** 참고 | 멘토 홈·학생 상세·수업 준비 | 최우선 |
| [Quizlet — 학습 화면 안내](https://help.quizlet.com/hc/en-ca/articles/360030841732-Studying-on-Quizlet) | 학습 카드, 문제 유형별 화면 구분, 짧은 학습 단위의 전환 | 선택지·오답 복습·학습 결과 카드 | 보충 |
| [Classkick](https://classkick.com/) | 학생의 풀이를 확인하고 피드백하는 화면, 여러 학생의 작업을 한눈에 보는 구성 | 멘티 풀이 기록·멘토 확인 화면 | 보충 |

### Brilliant

- 개념을 설명하는 시각 자료와 실제 문제를 어떻게 연결하는지 살펴본다.
- 학습자가 현재 진행 상황과 다음 학습 대상을 어떻게 파악하는지 확인한다.
- 배움길에서는 문제와 다음 행동이 먼저 눈에 들어오는 구성을 참고한다.

### 칸아카데미

- 공식 소개 페이지와 데모에서 교사가 자주 하는 작업의 배치를 살펴본다.
- 학생·과제·학습 보고서를 오가는 메뉴와 정보 구조를 참고한다.
- 배움길에서는 오늘 확인할 학생·개념·미확정 일지가 쉽게 드러나도록 정보 우선순위를 잡는다.

### Quizlet

- 학습 모드별로 문제와 조작 요소가 어떻게 구분되는지 살펴본다.
- 학습 카드와 진행 상황을 보여주는 단위를 참고한다.
- 배움길에서는 선택지, 오답 복습, 결과 카드를 반복해서 사용해도 익숙하게 느껴지는 구성을 참고한다.

### Classkick

- 학생이 남긴 풀이와 교사의 피드백을 함께 보여주는 방식을 살펴본다.
- 학생별 작업을 비교하거나 자세히 확인하는 화면의 정보 배치를 참고한다.
- 배움길에서는 점수 외에 실제 풀이 기록을 보고 멘토가 판단할 수 있는 구성을 참고한다.

## 3. 디자인 모음 사이트

### [Mobbin](https://mobbin.com/)

실제 출시된 앱·웹의 화면과 사용 흐름을 모아 둔 디자인 레퍼런스 사이트다. 개별 화면 요소를 비교하거나 제품 안에서 화면이 이어지는 방식을 살펴볼 때 활용한다.

검색할 키워드:

- `Education`: 교육·학습 서비스의 전체 구성
- `Quiz`: 문제·선택지·제출·결과 화면
- `Progress`: 진행 상황과 학습 결과 표시
- `Dashboard`: 멘토의 학생·수업·기록 관리 화면

## 4. 배움길에 적용할 디자인 방향

| 구분 | 중심 원칙 | 화면에서 확인할 점 |
| --- | --- | --- |
| 멘티 | 문제와 다음 행동에 집중 | 현재 문제, 선택지, 도움 요청, 제출·다음 단계가 쉽게 구분되는가 |
| 멘토 | 수업과 기록 업무의 우선순위를 명확하게 표시 | 오늘 확인할 학생·개념·미확정 일지를 빠르게 찾을 수 있는가 |
| 공통 | 읽기 쉽고 일관된 구성 | 충분한 여백, 읽기 쉬운 수식과 글자, 일관된 버튼·상태 표시를 사용하는가 |

## 5. 참고 순서

1. **Brilliant**로 멘티 문제풀이·기초 연습 화면의 방향을 잡는다.
2. **칸아카데미**로 멘토 홈·학생 상세·수업 준비 화면의 방향을 잡는다.
3. **Quizlet·Classkick**에서 카드·풀이 기록·피드백 표현을 보충한다.
4. **Mobbin**에서 필요한 화면 요소와 전환 사례를 비교한다.

각 레퍼런스에서는 배움길에 필요한 화면과 요소를 골라 참고하고, 실제 화면의 내용과 용어는 멘티·봉사 멘토의 사용 맥락에 맞춘다.
