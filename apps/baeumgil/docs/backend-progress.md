# 지훈 담당 구현 기록

기준: 배움길 PRD 및 2026-10-24 해커톤 MVP 개발 계획. 범위는 공통 데이터·저장·서버·회기/일지이며 FE·학습 엔진·AI 프롬프트는 기존 담당자의 구현을 사용한다.

- 시작 기준: 기존 학습 엔진·AI 계약 테스트 57개 통과.
- 기존 변경: `learning/engine.js`, `ai/contracts.js`, 관련 테스트는 다른 작업의 변경으로 보존한다.
- Ruling: 사용자가 이곳에서 지훈 작업을 진행하도록 지정했고 같은 저장소에 다른 담당의 변경이 진행 중이다. 현재 기능 브랜치에서 소유 파일만 추가하고 checkout·자동 커밋을 하지 않는다. 통합 담당자가 변경을 분리해 반영할 수 있도록 파일과 검증 결과를 남긴다.
- Ruling: 실제 학습 엔진은 명령 필드를 최상위에 받는다. 기존 동작을 바꾸지 않고 공통 계약은 실제 구조를 문서화한다.
- Ruling: 실제 AI 출력은 기존 모듈의 `priorities/mentorQuestions/plan` 구조를 사용한다. 구 계획의 `recommendations`를 별도 구현하지 않는다.
- Ruling: 서버 DB는 도입하지 않는다. PRD의 브라우저 로컬 저장을 유지하고 AI 호출용 로컬 서버·저장 계약을 제공한다.
- Pre-flight: 엔진→공통 상태는 기존 배열·동적 경로 필드를 보존한다. 저장→FE는 revision 기반 결과를 반환한다. AI 어댑터→공동 AI 계약은 기존 생성·검증 함수를 재사용한다. 회기→월별 조회는 날짜와 확정 스냅샷만 집계한다.

## 진행

- [x] B1 공통 상태 검증·로컬 저장 — 미구현 모듈 실패 확인 후 9개 테스트 통과. 기존 엔진 상태 보존, 읽기/쓰기 실패, 손상 원문 보존, revision 충돌, 초기화 확인 검증.
- [x] B2 회기·일지 확정·개정·철회·대장 — 미구현 실패 후 지훈 범위 누적 18개 테스트 통과. 일지 스냅샷·최신본·월 경계·선택 회기 학습 범위 검증.
- Ruling: 확정 이후 회기 원자료가 바뀌면 이전 일지는 보존하되 재확정 전 합산에서 제외한다. 선택 회기의 학습만 AI에 전달할 수 있도록 `createSessionSnapshot`을 제공한다.
- [x] B3 서버·Gemini 어댑터·연결 문서 — 키/모델 미설정, 허용 ID 검증, 시간 초과, 취소, 한도·네트워크 오류, 정적 경로 격리 검증. 공급자 HTTP 응답은 주입해 테스트했으며 실계정 Gemini 호출은 미검증이다. 현재 환경에 키·모델 설정이 없다.
- [x] B4 전체 회귀 검증·독립 코드 검토 — 독립 검토 1회 완료, 지적 3건 수정. 최종 `npm test` 91/91 통과, `npm run check:content` 오류 0·자체 제작 대표 문항 2개 출제 가능. 로컬 접속 제한 환경에서는 권한을 허용한 테스트 실행으로 실제 HTTP를 검증했다.
- 통합 검증: 실제 로컬 HTTP bootstrap → 전체 보충 단계 → 명령마다 저장/복원 → 실제 회기 → 주입 공급자의 AI 응답 검증 → 일지 확정 → 월별 합산을 연결했다. UI 조작 검증은 FE 연결 후 수행한다.
- 검토 수정: 확정 후 학습 근거 변경도 재검토/집계 제외 대상에 포함하고, 확정 시 학습 스냅샷을 보존한다. 같은 회기 반복 저장은 무변경으로 처리하며 회기 변경 이벤트는 전후 사실을 보존한다. 각각 실패를 재현한 테스트 3개를 추가한 뒤 수정해 통과했다.
- 검토 제외 판정: FE·기존 엔진/AI 내용은 담당 범위 밖이다. 원자적 다중 탭 저장·인증·DB·기기 공유는 문서대로 후속 범위다. 실계정 AI·공식 기출·기관 양식은 설정/자료가 필요하며 검증 전이라고 표시한다. 이 제외 항목은 범위 결정으로 수용한다.
- 인수인계: `README.md` 실행법과 `docs/backend-handoff.md`의 API·저장·일지 예시를 기준으로 FE에 연결한다. 외부 배포·실계정 호출·FE 통합 완료로 해석하지 않는다.
- 브랜치 인계(2026-10-24): 사용자가 기존 `ver2`에서 FE·BE·엔진 통합 버전을 이어 가도록 지정했다. 현재 checkout이 이미 `ver2`임을 확인했으며, 지훈 담당 신규 파일 18개를 로컬 커밋 대상으로 정했다. 브랜치 기본 이력에는 기존 엔진·AI 및 미리보기 작업이 포함되어 있다. 인계 직전 전체 테스트 91/91·콘텐츠 검증을 다시 통과했다.
