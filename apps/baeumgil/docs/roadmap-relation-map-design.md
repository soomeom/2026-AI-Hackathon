## 1. 목표
- 로드맵의 `단계별 카드` 보기(영역 → Step 1~3 카드 목록, 세로로 긴 스크롤)를 **원 노드가 선으로 연결된 지도 한 장**으로 바꾼다.
- 37개 개념 · 26개 선수 관계 · 6개 영역 · 학생 상태를 **스크롤 없이 한 화면**에서 본다.
- 노드를 누르면 그 개념까지 가는 길이 강조되고, 문제별 기록 패널로 이어진다.

### 2.1 배치 방향 판단: 왼쪽→오른쪽 대신 아래→위
- 우리 데이터는 깊이가 3단계(기초·선수·고졸)뿐이고, 선수 관계는 **같은 영역 안에서만** 있다(26개 모두).
- 왼쪽→오른쪽(참고 화면 방식): 열 3개 + 목표, 행은 영역 6개 × 최대 3개 = 13행 → 높이 약 750px. 한 화면에 안 들어옴.
- **아래→위(채택)**: 영역 6개 = 6개 기둥, 기둥 안에서 기초(아래) → 선수 → 고졸(위) → 맨 위 목표. 높이 약 480px로 한 화면에 들어옴. 선이 기둥 안에서만 오르내려 **교차가 없다**. "배움길을 올라 목표에 닿는다"는 비유와도 맞음.

### 3.1 노드
- 원 반지름 18. 이름은 원 아래 최대 2줄(줄당 7자 안팎, 넘치면 말줄임 + 툴팁에 전체 이름).
- 원 안: **추천 학습 순서 번호**(보완 필요·다시 확인 개념만, 기초부터 순서) · 확인된 개념은 ✓ · 미확인은 비움.
- 고졸 단계 노드는 테두리를 굵게(목표에 직접 닿는 개념).
- 보충 연습을 모두 마친 개념은 오른쪽 위에 작은 ✓ 배지(진단 판정과 구분).
- "지금 여기"(추천 시작 개념)는 점선 후광.

### 3.2 선
- 선수 관계: 회색 곡선 + 화살표(아래 → 위).
- 고졸 노드 → 목표: 청록 점선.
- 선택 시: 선택 개념의 선수 사슬 노드·선은 진하게, 나머지는 20% 투명도.

### 3.3 영역 기둥
- 기둥 바닥에 영역 이름 + "도움 없이 확인 k/n".
- 기둥 사이에 옅은 세로 구분 띠(영역 구분이 색에 기대지 않게).
- 왼쪽 가장자리에 단계 눈금(기초 · 선수 · 고졸).

### 3.4 지도 아래
- 왼쪽: 기존 **문제별 기록 패널**(진단에서 푼 문제 / 보충 연습 문제 / 해설과 보충 문제 풀기).
- 오른쪽: **추천 학습 순서 칩** — 번호 붙은 개념을 순서대로, 누르면 그 노드 선택.

## 4. 보기 전환과 역할
| | 학생 | 멘토 |

| 기본 보기 | 내 배움길(현재 초점형 경로) | **관계 지도**(전체 조망이 멘토의 기본 작업) |

- 보충 문제 풀이 화면(`renderRoadmap`의 연습 모드)은 그대로 유지. 단계별 카드 **목록**만 없앤다.

## 5. 반응형 · 접근성
- 지도는 SVG 하나(viewBox 약 1000×480)로 그려 폭에 맞춰 줄어든다. 760px 미만에서는 최소 폭 900px로 두고 지도 칸 안에서 가로 스크롤 + "옆으로 밀어 보기" 안내. 모바일 기본 보기는 `내 배움길`.
- 노드는 `<g role="button" tabindex="0">` + Enter/Space로 선택, `aria-label`에 "이름 · 단계 · 상태 · 학습 순서".
- 지도 옆에 같은 내용의 목록(영역별 개념 · 상태)을 스크린리더용으로 둔다(색·모양 외 텍스트 대체).
- 클릭 처리기를 `closest('button')`에서 `closest('[data-map-action]')`로 넓힌다(SVG 노드 지원).
- 애니메이션은 9절의 확대 이동 하나뿐. `prefers-reduced-motion`이면 바로 이동.

## 9. 노드 확대 (선택 시 부드럽게 다가가기)
- 지도 위 버튼: `전체 보기` · `개념 확대`(참고 화면의 지도 전체 보기 / 개념 관계 보기와 같은 역할).
- `개념 확대` 상태에서 노드를 고르면 그 개념 + 선수 사슬 + 목표 연결이 들어오는 영역으로 SVG `viewBox`를 옮긴다.
  - 영역 = 사슬 노드들의 외곽 + 여백 40, 지도 비율 유지, 최소 폭 = 전체의 40%(너무 크게 확대해 글자가 깨지지 않게), 지도 밖으로 나가지 않게 고정.
  - 이동은 약 0.5초 부드러운 곡선(ease-in-out). `prefers-reduced-motion`이면 애니메이션 없이 바로 이동.
- `전체 보기`를 누르거나 Esc → 전체로 돌아온다. 선택 강조는 유지.
- 다시 그릴 때(rerender) 확대 상태가 튀지 않도록 마지막 viewBox를 `ui.mapViewBox`에 기억해 그 자리에서 시작한다.
- 확대는 보기 방식일 뿐 저장 기록에 쓰지 않는다.
- 구현: `relationViewBox(layout, nodeIds)`(계산, 테스트 대상) + `animateViewBox(svg, from, to)`(브라우저 전용, rerender 뒤 호출).
