# 배움길 동기부여 · 로드맵 · 내비게이션 재설계

작성 2026-10-24 · 대상 ver2 (`apps/baeumgil`) · 상태: 3·4절 구현 완료, 5.2~5.4 미구현(발표에서 계획으로 언급)

## 1. 목표와 원칙

학교 밖 청소년이 **끊기지 않고 다시 돌아오게** 만들되, 진단·학습 데이터의 신뢰도를 해치지 않는다.

| 원칙 | 뜻 |
|---|---|
| 손실보다 성장 | "잃는다"(연속 기록 끊김) 대신 "늘었다"(혼자 풀 수 있게 된 개념)를 보여 준다 |
| 양보다 근거 | 문제 수·접속 일수로 보상하지 않는다. 도움 없이 처음 푼 정답만 성장으로 센다 |
| 사람이 인정 | 배지·포인트보다 멘토의 한마디가 보상이다 (멘토링 코파일럿 정체성) |
| 리듬은 주 단위 | 멘토 수업 주기(주 1~2회)에 맞춘다. 매일 접속을 전제로 하지 않는다 |

### 하지 않는 것 (근거)
- **연속 학습(Streak)**: 불규칙한 생활·실패 경험이 있는 사용자에게 끊김은 또 하나의 실패 경험. 매일 사용 전제가 실제 사용 방식과 다름.
- **일일 퀘스트·포인트·보석**: "많이·빨리" 풀기를 보상 → 찍기, 도움 체크 생략 유인 → 진단 근거(`independent`)와 엔진 단계 오염.
- **마스코트·보물상자**: 10대 후반에게 유치하게 느껴질 수 있고 차별점이 아님.

## 2. 판정 기록

### 2.1 듀오링고 경로를 그대로 쓰는 안 → 부분 채택
| 가져온 것 | 버린 것 |
|---|---|
| 지금 할 개념 하나를 확실히 강조 | 큰 원형 노드 + 지그재그 (화면당 5~6개, 스크롤이 더 길어짐) |
| 노드는 모양·색으로 상태 표시, 글자 최소 | 한 줄 직선 경로 (선수 관계가 사라짐) |
| 경로 형태의 세로 진행 | 전체를 볼 방법이 없는 구조, 보물상자·캐릭터 |

### 2.2 "현재 단계는 크게, 나머지는 작게" → 채택 (조건부)
- 강조 단위는 **열(Step)이 아니라 영역(행)과 개념(노드)**. 학생은 영역마다 위치가 달라서 Step 열을 강조하면 목표(고졸)가 작아진다.
- 작게 줄인 점도 터치 영역 36px 이상, 색 + 모양(○◐●·) 병기.
- 멘토 화면에는 적용하지 않는다(학생 간·영역 간 비교가 왜곡됨).

## 3. 로드맵 화면 (구현됨)

### 3.1 이전 문제
- 노드 카드 높이 122px, 6영역 × 3단계 약 37개 → "전체 보기" 높이 약 2,400px.
- 추천 경로 / 영역별 / 전체 어느 범위든 스크롤이 길고, 지금 위치와 전체가 함께 안 보였다.

### 3.2 학생: 초점형 지도
```
 수와 다항식   0/6  ○ ○ │ ○ ○ │ ○ ○          ← 접힌 영역: 점 한 줄 (기초│선수│고졸)
 방정식        0/6  · · │ ○ · │ ○ ·
┌ 함수와 그래프 ───────────────── 도움 없이 확인 0/6 ┐  ← 펼친 영역
│ ◎ 일차함수의 뜻   [상세 카드: 상태·근거·보충 문제 풀기·앞뒤 개념] │
│ ○ 일차함수의 그래프                       선수 · 보완 필요 │
│ · 이차함수의 꼭짓점                 고졸 · 목표 · 미확인 │
└────────────────────────────────────────┘
 도형과 좌표   0/8  · · · │ · · · │ · ·
```
- 펼칠 영역: `ui.mapDomainId` → 없으면 선택/추천 개념의 영역.
- 펼친 영역 안에서 먼저 열 개념(`focusNodeOf`): 추천 → 보완 필요 → 혼자 다시 확인 → 첫 개념.
- 다른 영역의 이름이나 점을 누르면 그 영역이 펼쳐지고 원래 영역은 점 한 줄로 접힌다.
- 고졸(목표) 개념은 접혀도 점으로, 펼치면 "목표" 표시로 항상 보인다.
- `추천 경로 / 영역별 / 전체` 버튼은 없앴다. `단계별 카드` 보기는 유지.

### 3.2-1 코드트리식 두 칸 배치 (채택·구현)
- 판정: 이전 화면은 개념의 진단 상태만 보이고 **문제별로 한 것/안 한 것**은 눌러야 보였다. 코드트리의 "왼쪽 경로 + 오른쪽 고정 상세 패널"이 이를 해결 → 채택. XP·연속 학습·포인트·자물쇠·예상 시간·난이도는 제외(근거 없는 수치, 선수 관계는 권장이지 강제가 아님).
- 왼쪽: 초점형 경로. 각 줄에 `기초 · 지금 여기 · 연습 1/2`처럼 진행 수를 표시.
- 오른쪽 패널(지도 폭 860px 이상에서 고정, 좁으면 경로 아래):
  - 개념 이름 + 보충 연습 진행률 막대(%)
  - **진단에서 푼 문제**: 문제마다 ✓ 맞힘 / ✓ 도움 받고 맞힘 / ✗ 틀림 / ? 모름
  - **보충 연습 문제**: 문제마다 최근 결과 또는 ○ 아직 안 풂. 줄을 누르면 그 문제를 연다
  - 먼저 볼 개념 · 다음 개념
  - "해설과 보충 문제 풀기 →": **아직 맞히지 않은 첫 문제**부터 연다
- 데이터는 기존 진단 응답·보충 문항·보충 연습 기록만 사용(엔진·저장 형식 변경 없음, `lessonRows`).

### 3.2-2 코드트리 개요 창 구조 (채택·구현, 화면 복제는 하지 않음)
- 판정: 화면을 그대로 복제하면 심사에서 "따라 했다"는 인상을 주고, 고유 디자인(육각 배지·캐릭터·색·문구)은 도용 소지가 있다. → **정보 구조·동작만 가져오고 겉모습은 배움길 것**(청록, 원형 노드, 자물쇠·XP 없음).
- 학생 메인 화면은 **과정 카드 + 지금 영역 경로 + 오른쪽 문제별 기록**만 남겼다. 접힌 영역 줄은 메인에서 뺐다.
  - 과정 카드 "고졸 검정고시 수학 ▾" → 전체 보기 창
  - 영역 머리표 "n. 영역 이름 ▾"(눌러도 전체 보기 창) + ‹ › 이전/다음 영역
  - 지금 개념은 경로 안 순번(1, 2, …)으로 강조
- 전체 보기 창(대화상자): 왼쪽 과정(고졸 = 목표 과정, 중졸 = 준비 중·기초 개념은 고졸 과정에 포함), 오른쪽 6개 영역 = 번호·이름 + 설명 + 도움 없이 확인 수 + 개념별 점. 영역·점을 누르면 닫히고 그 영역이 펼쳐짐. Esc·배경·닫기로 닫고 과정 카드로 포커스 복귀. 좁은 화면에서는 하단 시트.
  - 영역 설명은 지어내지 않고 실제 개념 이름으로 생성(`chapterSummary`: "시작 개념에서 시작해 고졸 목표 개념까지 이어져요.")
- 첫 수준 확인 안내(코드트리 "갭체크" 자리): 진단 전·진행 중인 학생에게만 오른쪽 패널 맨 위에 표시.

### 3.3 멘토: 같은 크기 매트릭스
- 6개 영역 모두 점 한 줄 + 오른쪽 문제별 기록 패널. 한 화면에서 학생 전체 상태와 선택 개념의 문제별 결과를 함께 본다.

### 3.4 성장 지표
- 요약 칸 "도움 없이 확인한 개념 n개 / 전체 · 고졸 m개" (`growthCount`: `mastered` + `confirmed`).
- 보충 연습 완료는 세지 않는다(기존 정책 "연습 완료는 진단 판정을 바꾸지 않음" 유지). ✓ 표시로만 구분.
- 영역마다 "도움 없이 확인 k/n".

### 3.5 멘토 홈 다이어그램 (구현됨)
- **멘토링 흐름도**: 첫 수준 확인 → 시작점 정하기 → 보충 학습 → 다시 풀기 → 수업·일지. 각 단계에 실제 기록 요약(예: "8문제 응답 · 중간 결과", "보완 개념 0/8 연습 완료")과 완료/지금 단계/대기 상태. 지금 단계는 항상 하나. 단계를 누르면 해당 화면으로 이동. 좁은 화면에서는 세로 흐름.
- **영역별 개념 상태 막대**: 영역마다 누적 막대(도움 없이 확인 / 혼자 다시 확인 / 보완 필요 / 미확인), 막대 길이 = 그 영역의 개념 수. 오른쪽에 "확인 수/전체 · 보완 n" 숫자. 색은 dataviz 검증 스크립트로 확인(인접 쌍 색약 ΔE ≥ 8, 대비 ≥ 3:1), 범례에 모양(●◐○·) 병기, 스크린리더용 표 제공.
- 흐름도와 정보가 겹치는 기존 숫자 칸 3개는 뺐다.
- 파일: `public/src/ui/mentor-diagrams.js`, `public/overview.css`, 테스트 `tests/mentor-diagrams.test.js`.

## 4. 좌측 접이식 내비게이션 (구현됨)

| 화면 | 동작 |
|---|---|
| 넓은 화면(>900px) | 왼쪽 고정 사이드바 232px. 상단 버튼으로 아이콘만(68px) ↔ 펼침 전환. 상태는 이 브라우저에 기억(`baeumgil.navCollapsed`) |
| 좁은 화면(≤900px) | 상단 ☰ 버튼으로 서랍 열기. 배경(스크림) 클릭·Esc·메뉴 선택 시 닫힘. 서랍은 항상 이름까지 표시 |

- 멘티 메뉴: 학습(나의 학습, 로드맵)
- 멘토 메뉴: 학생(멘토 홈, 로드맵, 학습 기록) · 수업(수업 준비, 회기·일지)
- 현재 페이지는 `aria-current="page"`로 강조. 진단 상세는 "학습 기록"으로 표시.
- 회기·일지에서 저장 안 한 입력이 있으면 다른 메뉴로 나가기 전에 확인(기존 탭과 같은 보호).
- 멘토 화면 상단의 탭 줄은 사이드바로 옮기고, 학생 이름 옆에는 현재 페이지 이름만 남겼다.
- 역할 바꾸기·과목 선택·시연 초기화는 상단 바에 그대로 둔다.
