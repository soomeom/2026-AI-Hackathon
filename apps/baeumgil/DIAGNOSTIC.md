# Astra 적응형 진단과 맞춤형 학습 로드맵

## 실행·검증

저장소 루트에서 `python3 -m http.server 8766 --bind 127.0.0.1 --directory apps/baeumgil/public` 실행 후 http://127.0.0.1:8766/ 접속.
전체 수식·도형 대조는 `/review.html`. 테스트는 `node --test apps/baeumgil/tests/*.test.js`.

## v2 개념 관계

6영역의 고졸 본 문항 → 1차 선수 개념 → 2차 기초 개념을 지정한다. 현재 내용 검증은 코드 작성자의 연산·논리 검토이며 교육 전문가 검증은 별도다. 오답 원인은 확정 진단이 아닌 추가 확인 가설이다.

| 본 문항 | 1차 선수 | 2차 선수 |
|---|---|---|
| 다항식 덧셈 | 동류항 정리·일차식 계산 | 부호·계수 덧셈 |
| 세제곱식 인수분해 | 이차식 인수분해 | 부호·계수 덧셈 |
| 판별식 | 판별식 부호·실근 개수 | 제곱·사칙연산 |
| 근과 계수 | 곱셈 공식·제곱근 | 제곱·사칙연산 |
| 이차함수 최솟값 | 이차함수 꼭짓점 | 제곱의 비음수 성질 |
| 합성함수 | 함숫값 대입 | 문자 대입·연산 순서 |
| 선분 내분 | 선분의 비례 | 비·분수 계산 |
| 점·직선 거리 | 피타고라스·직선 기본형 | 좌표 대입·제곱 계산 |
| 집합 연산 | 합집합·교집합 원소 | 원소 판별 |
| 필요조건 | 명제 진리집합 포함 관계 | 명제 참·거짓 |
| 경우의 수·조합 | 중복 없이 조합 나열 | 조건에 맞는 경우 세기 |

직접 선수 확인용 자체 제작 36문항 추가. 전체 진단용 은행은 기존 38개를 포함해 74개. 진단에 사용하지 않는 기존 보조 문항의 약한 연결은 비우고 supplementary로 표시했다. 기존 보충 학습 8문항은 보존한다.

## 진단 기록

`attempts` 항목: id, domain, questionId, conceptIds, stage(high_school / prerequisite_1 / prerequisite_2), originQuestionId, level, result(correct / incorrect / abstained), choiceId, independent, helpUsed, submittedAt.

진단은 최초 고졸 문항에서 시작하며 오답·모름이면 명시된 직결 선수로 이동한다. 선수 개념의 재확인은 같은 개념의 다른 문항을 사용한다. 단순히 같은 영역의 더 쉬운 문항을 임의로 대체하지 않는다. 문항 표시 시 노출을 기록하고, 이전 노출·도움 정답은 독립 수행에서 제외한다. 최대 30문항.

기존 수준 판정은 영역·수준별 독립 정답 2개 기준을 유지한다. 결과는 선별 문항의 학습 시작점 추정이며 전체 교육과정·합격 예측·표준화된 검사로 해석하지 않는다.

## 로드맵·보충 학습

`learning/roadmap.js`가 실제 오답·모름 로그를 개념별로 묶어 생성한다.

- Step 1: 2차 하위에서 막힌 기초 개념
- Step 2: 1차 하위에서 막힌 선수 개념
- Step 3: 처음 틀린 고졸 개념 재도전
- 독립적으로 맞힌 고졸 문항 개념은 진단 통과로 표시. 검사하지 않은 개념은 통과시키지 않는다.

각 카드에는 응답 근거와 관련 문항을 연결한다. 영역 안에서 하위 단계 카드의 모든 문제를 맞히면 다음 단계가 열린다. 다른 영역은 독립적으로 학습할 수 있다. 해설 열람·오답 재시도 가능. 연습 후 다음 단계가 열리는 것은 연습 완료이며 개념의 영구 숙달 판정은 아니다.

`practiceAttempts`는 진단 로그와 분리하며 진단 티어를 변경하지 않는다. JSON 내보내기에 두 로그와 로드맵이 포함된다. 새로고침 시 두 로그를 재실행하여 검증하고 복원한다. 저장 키는 astra-diagnostic-v2이며 이전 v1 기록을 삭제하지 않는다. 과거 문항 노출 기록은 그대로 유지한다.

## 콘텐츠 확장

1. `scripts/prepare_exam_assets.py`: 40쪽·400문항 영역 이미지와 정답 초안.
2. `scripts/register_diagnostic_set.py`: 원본 대조한 2025년 1회 전사 세트 등록 및 도형 크롭. 마지막에 아래 3번을 자동 실행.
3. `scripts/correct_prerequisites.py`: 자체 제작 선수 문항, 교정 경로, 개념 그래프, diagnostic.json v2 반영. 반복 실행 가능.
4. 테스트 및 review.html 검사.

원본 400문항 중 기출 31개가 등록되어 있고 나머지 369개는 초안 상태다. 로컬 콘텐츠 승인과 기출 재배포 이용 조건은 별개이며 usageReviewStatus=unverified를 유지한다. KaTeX 0.16.22는 로컬 포함되어 수식 렌더링에 외부 호출이 필요하지 않다.
