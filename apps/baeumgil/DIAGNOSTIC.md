# Astra 적응형 진단 시제품

## 실행

저장소 루트에서 `python3 -m http.server 8766 --bind 127.0.0.1 --directory apps/baeumgil/public` 실행 후 http://127.0.0.1:8766/ 접속.
문항·수식·이미지 전체 대조 화면: http://127.0.0.1:8766/review.html
Node가 설치된 환경에서 `node --test apps/baeumgil/tests/*.test.js`로 테스트.

## 연결된 범위

- questions.json에 진단용 38문항 추가: 2025년 1회 고졸 12개, 중졸 19개, 자체 제작 7개. 기존 8문항 보존.
- role=diagnostic 문항은 diagnostic.json의 여섯 영역 진단에 사용. 기존 보충 학습의 original 문항 목록과 별도이며 기존 gradeAnswer 채점기를 공유.
- 원본 페이지·확정 정답표를 시각 대조하고 수식을 전사. 수식·원본 문항 이미지·별도 도형 16개·해설 포함.
- approved는 로컬 진단 콘텐츠 전사·계산 확인을 뜻함. 개별 기출의 재배포 이용 조건 승인이나 전문가 난이도 검증을 뜻하지 않음. usageReviewStatus=unverified와 educatorValidated=false를 보존.
- 6영역: 수와 다항식, 방정식과 부등식, 함수와 그래프, 도형과 좌표, 집합과 명제, 경우의 수와 확률. 전 교육과정의 모든 소단원을 검사하는 검사는 아님. 통계 2개는 추가 문제은행 콘텐츠이며 기본 6영역 검사에는 포함하지 않음.

## 진단 규칙 v1

각 영역의 고졸 문항으로 시작. 정답이면 같은 수준의 다른 문항을 확인하고 오답·모름이면 문항별 fallback_question_id를 우선하여 더 낮은 선수 개념을 검사한다. 최하위 수준에서 막히면 다른 기초 문항을 한 번 더 확인한다. 이미 제출한 문제를 반복하지 않으며 최대 30문항에서 종료한다.

한 영역에서 같은 수준의 처음 보는 문항 두 개를 도움 없이 맞히면 그 수준의 수행 근거로 기록한다. 전 영역 고졸 근거가 있으면 '고졸 핵심 수준', 3영역 이상 고졸 근거가 있으면 '고1 기초~고졸 핵심 혼합', 그 밖에는 영역별 확인 수준의 중앙값으로 수업 시작점을 제안한다. 이는 전문가가 보정한 능력 추정 모형이나 학년 진급 판정이 아닌 명시적인 초기 운영 규칙이다. 미완료 영역과 도움 받은/재노출 정답은 독립 수행 근거로 사용하지 않는다.

문항 최초 표시 시 노출을 저장하고, 새 검사에서도 과거 노출을 유지한다. 저장 기록은 규칙을 재실행해 복원한다. 손상된 기록은 알림을 띄우고 신규 여부 불명으로 보수적으로 처리한다. 재진단 시 반복 노출 때문에 확인 근거가 부족할 수 있으며 새로운 동형 문항 확장이 필요하다.

## 콘텐츠 확장 파이프라인

1. scripts/prepare_exam_assets.py: 전체 원본 40쪽과 400문항 영역 이미지·정답 연결 초안 생성.
2. scripts/register_diagnostic_set.py: 시각 대조한 전사 자료만 승인 병합. 개념·확정 정답 매핑·진단 경로 생성. 반복 실행 가능.
3. scripts/crop_diagnostic_figures.py: 전사 세트의 검토한 좌표로 도형을 분리. 2번 스크립트가 자동 호출.
4. tests/diagnostic.test.js와 review.html에서 LaTeX, 정답, 자산, 분기와 결과 확인.

다음 회차는 원본 대조한 rows와 도형 좌표를 추가한 뒤 같은 등록·검증 절차를 실행한다. 자동 PUA 치환으로 분수·지수·근호 구조가 복원되었다고 간주하지 않는다. 원본 400개 중 31개가 현재 진단에 등록되어 있고 369개는 이미지·정답 초안 단계다. 2026년 2회 가안은 현재 작동 세트에 포함하지 않았다.

## 검증

- 기존 53개 + 신규 9개 테스트 통과: 정상·오답·모름·재노출·도움·중복 제출·중단 한도·정답 매핑·LaTeX 및 이미지 경로.
- 브라우저에서 고졸 오답 → 중졸 지수법칙 → 같은 수준 재확인 → 6영역 완료 → 혼합 수준·취약 개념 결과 확인.
- 새로고침 후 다음 문항 복원 확인. 좁은 패널에서 수식·좌표 그래프 표시 확인.

실제 학생 응답 데이터로 문항 난이도, 선수 연결의 교육적 타당성, 오진률 및 티어 기준을 검증해야 한다. 결과는 항상 추정으로 표시한다.
