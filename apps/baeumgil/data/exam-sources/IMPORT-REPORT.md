# 기출 문항 변환 진행 보고

## 생성 및 자동 검사 완료

- 원본 문제지 20개, 총 40쪽을 2배 해상도 PNG로 렌더링.
- 각 시험의 1~20번 위치를 검출해 총 400개의 문항 영역 이미지 생성.
- 발문·도형·그래프·선택지가 포함된 영역을 저장. 도형만 분리한 에셋은 아직 없음.
- 전체 문항 번호의 누락·중복 검사 통과.
- 400문항과 math-answer-keys.json의 정답 번호 연결 완료.
- 생성 이미지 전체의 파일 존재·PNG 디코딩 검사 통과.
- 2022년 1회 고졸 7번은 직접 이미지 확인: 발문, 이차함수 그래프, 선택지 4개 보존.
- 전체 문항의 육안 대조 검수는 미완료. 영역 자동 검출만으로 잘림이 없다고 보증하지 않음.

## 파일

- 생성기: ../../scripts/prepare_exam_assets.py
- 에셋: ../../public/assets/exams/
- 문항별 초안: question-drafts.json
- 정답 목록: math-answer-keys.json

실행 환경: Python + pdfplumber + pypdfium2 + Pillow. PyMuPDF 대신 설치된 PDFium을 사용.

한국교육과정평가원이 검정고시 기출문제·정답을 제공하는 기관임은 아래 공공기관 안내에서 확인:

https://www.goe.go.kr/goe/na/ntt/selectNttInfo.do?mi=10961&nttSn=2345608

개별 원본 파일과 공식 게시물의 대조, 개별 첨부파일 이용 허락 조건은 미확인.
출처 기관 표기만으로 변경·재배포 허용을 확정하지 않음.
2026년 2회 답지는 제공된 파일명 기준 가안이며 최종 정답표라고 표시하지 않음.

## 최종 연결 전 남은 작업

1. 20개 수학 정답표를 원본 화면과 대조하고 검수 이력 기록.
2. 400문항의 발문·선택지 수식을 LaTeX로 전사하고 이미지와 대조.
3. 개념·난이도·해설·보충 경로 및 필요한 추가 문항 틀 작성·검수.
4. 사용자 확인상 UI 미구현. 프론트엔드 수식/이미지 표시 규격 구현 및 실제 화면 테스트 필요.
5. 위 검사 통과 후 승인 문항만 기존 questions.json에 병합.

현재 기존 엔진의 승인 조건을 우회하거나 미검수 문항을 approved로 바꾸지 않았음.
