# 검정고시 수학 원본 자료

사용자가 제공한 2022~2026년 1·2회 문제지 20개를 원본 그대로 보관합니다.

- `high/`: 고졸 10개
- `middle/`: 중졸 10개
- `manifest.json`: 연도·회차·학교급·원본 파일명·페이지 수·SHA-256 및 검수 상태

PDF 첫 페이지의 고졸/중졸 표기를 확인했습니다. 연도·회차는 제공된 파일명 기준입니다. 각 파일은 2쪽입니다.

## 현재 상태

원본 보관 단계이며 문항별 문제은행이나 DB에 등록된 상태가 아닙니다. 기존 public/src/content/questions.json과 학습 엔진에는 연결하지 않았습니다.

수식의 텍스트 추출 결과에 사설 유니코드 글리프가 포함되어 있으므로 추출 문자열을 그대로 문제로 사용하지 않습니다. 페이지 렌더링과 수식·도형 대조 검수가 필요합니다.

정답표 원본 20개를 문제지와 연결했습니다. 원문 출처 URL과 수록·재배포 이용 조건은 미검토이며 콘텐츠 상태는 pending을 유지합니다.

## 다음 단계

1. 공식 출처 URL·이용 조건 및 정답표 확인
2. 우선 사용할 고졸 대표 문항 선정
3. 페이지 이미지와 대조해 문제·선택지·수식·도형 구조화
4. 정답·개념 태그·보충 경로 검수 후 승인 문항만 문제은행 연결

이 폴더는 공개 웹 경로 밖에 있습니다. GitHub 업로드는 별도로 진행합니다.

## 정답표 추가

- 전 과목 답지 20개에서 수학 정답표 페이지를 찾아 math-answer-keys.json에 400개 정답을 추출했습니다.
- 회차마다 문항 1~20의 연속성·중복·선택지 범위를 검사했습니다. 시각 대조 전이므로 앱 채점에는 연결하지 않습니다.
- 파일명 기준 2026년 2회 중졸·고졸은 가안(provisional), 나머지 18개는 확정안(final)입니다. 최신 확정 여부는 별도 확인이 필요합니다.
