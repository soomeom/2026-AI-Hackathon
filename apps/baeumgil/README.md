# 배움길 MVP 실행

지훈 담당 구현: 공통 데이터, 브라우저 저장, 실제 회기·일지·월별 대장, 로컬 HTTP 서버와 Gemini 호출 어댑터.

## 실행

Node.js 24 이상에서 이 디렉터리를 열고 실행한다. 외부 npm 패키지 설치는 필요 없다.

```powershell
cd C:\dev\gangwon\ver2\apps\baeumgil
npm run dev
```

- 화면: `http://127.0.0.1:4173/` (멘토·멘티 역할 전환)
- 상태 확인: `http://127.0.0.1:4173/api/health`
- 초기 데이터: `http://127.0.0.1:4173/api/bootstrap`

## 화면 구성

| 역할 | 화면 | 내용 |
| --- | --- | --- |
| 멘티 | 첫 수준 확인 | 6개 영역 적응형 진단(12~30문항), 모름·도움 사용 구분, 중간 저장·재개, 결과와 멘토 지정 대기 |
| 멘토 | 첫 수준 확인 결과 | 영역별 수준·판단 보류·응답 근거, 추천 시작 단원, 멘토의 시작점·첫 문제 확정 |
| 멘토 | 학습 근거·수업 준비 | 문항 지정, 단계별 정답률(최초·재도전·새 문제 분리), 경로별 응답 기록, 개념별 근거, 단계 조정, AI 수업 제안·채택 |
| 멘토 | 회기·활동일지·월별 대장 | 회기 입력(날짜·출석·활동 시간·관찰 메모), 사실 요약 초안, AI 활동 문장, 검토 후 확정, 월별 합산·표 복사 |
| 멘티 | 배움길 | 기출 풀이 → 개념 확인 → 기초 연습 → 유사 문제 → 기출 재도전 → 새 문제 확인, 모름·힌트·풀이·도움 요청·멈추기 |

처음에는 **멘토로 체험하기 / 멘티로 체험하기** 입장 화면이 나온다. 멘토는 ‘오늘 할 일’로, 멘티는 지정된 학습이 있으면 이어 풀기로 이동한다. 학습이 없으면 기존 첫 수준 확인·멘토 지정 대기 화면으로 이동한다.

상단의 **역할 바꾸기**로 입장 화면에 돌아와도 학습 응답·첫 수준 확인·회기·확정 일지는 유지된다. 작성 중인 일지 초안도 페이지를 새로고침하기 전까지 유지한다. 저장하지 않은 회기 입력은 역할을 나가기 전에 확인한다. 멘티 화면을 벗어나면 풀이 시간과 진행 중인 AI 요청을 멈춘다.

학습 기록은 기존 브라우저 `localStorage`에 자동 저장한다. 입장 역할만 탭별 `sessionStorage`에 저장하므로 같은 탭의 새로고침은 역할을 유지하고, 입장 상태가 없는 새 탭은 입장 화면부터 시작한다. 브라우저의 탭 복제는 입장 상태를 복사할 수 있다. 상단의 ‘시연 초기화’는 두 번 눌러야 기록을 지운다.

첫 사용은 **멘티로 체험하기 → 첫 수준 확인 → 역할 바꾸기 → 멘토로 체험하기 → ‘오늘 할 일’에서 시작 단원·첫 문제 선택 → 확정 → 역할 바꾸기 → 멘티 학습**으로 시연한다. 첫 수준 확인은 6개 영역을 고졸 문항부터 살피고 어려우면 관련 기초 문항으로 이동한다. 짧은 시연에서는 한 문제 이상 응답한 뒤 ‘여기까지 하고 멘토에게 넘기기’를 사용할 수 있다. 초기 결과는 수업 시작점을 위한 참고이며 전체 수학 실력이나 숙달 판정이 아니다. 초기 응답은 기존 학습 정답률·회기 시간과 분리한다. 기존 학습이 있는 학생은 첫 수준 확인을 거치지 않고 이어서 푼다. 이전 고정 7문항 기록은 저장본에 남지만 새 적응형 진단 결과로 사용하지 않는다.

## AI 설정

`.env.example`을 같은 폴더의 `.env`로 복사하고 `GEMINI_API_KEY`, `GEMINI_MODEL`을 채운 뒤 서버를 다시 시작한다. 모델 ID는 계정에서 사용 가능한 값을 접두어 `models/` 없이 입력한다. `GOOGLE_API_KEY` 환경변수도 대체 키로 지원한다. 키는 서버 환경에만 둔다.

설정이 없으면 AI API는 503을 반환한다. `configured: true`는 설정 유무이며 실제 계정 권한·호출 성공 보증이 아니다. 무료 사용 가능 여부와 한도는 계정에서 확인한다. 자동 테스트는 공급자 응답을 주입해 검증한다.

로컬 연결 확인(2026-10-24): `C:\dev\gangwon\ver2\apps\baeumgil`의 Git 제외 `.env`를 사용해 `gemini-3.1-flash-lite` 모델의 수업 계획·일지 문장 생성을 각각 검증했다. 두 요청 모두 HTTP 200·`source: live`로 반환되고 공동 출력 검증을 통과했다. 키는 서버 설정에만 보관한다. 실행 중인 서버는 설정 변경 후 다시 시작한다.

## 검정고시 기출 문제은행

`node scripts/build-exam-bank.mjs`로 `data/exam-sources`의 중졸·고졸 기출(2022~2026, 400문항)을 `public/src/content/exam-bank.json`으로 만든다.

- 출제 가능: 확정 정답 회차 360문항 (수식 전사 31 + 원본 문항 이미지 329). 2026년 2회 40문항은 가안 정답이라 제외(pending).
- 이미지 문항은 원본 문항 이미지와 공식 정답표 번호로 채점한다. 이용 조건 확인 전이며 화면에 출처를 표시한다.
- 문항 이미지: `py -3 scripts/trim_exam_question_images.py`로 원본 페이지에서 다시 잘라 바닥글(기관 로고·쪽 표시)과 가운데 세로 구분선을 뺐다 (40쪽 모두 바닥글 선 검출).
- 단원 분류(확정 정답 360문항): 수식 전사 31, 이미지로 직접 확인 131(수정 11 + 자동 분류 확인 92 + 번호 위치 추정 확인 28), 핵심어 자동 분류 198. 확인·수정 결과는 `data/exam-sources/concept-overrides.json`에 있고 스크립트가 자동 분류보다 먼저 쓴다. 회차마다 번호가 ±1 밀리므로 번호만으로 단원을 정하지 않는다.
- 보충 경로(`kind: exam_pool`): 개념 확인·기초 연습 = 선수 단원의 중졸 기출, 유사 문제·새 문제 확인 = 같은 단원의 다른 회차 기출(기출이 적은 판별식·산포도는 가장 가까운 단원으로 채움). 새 문제 확인은 학생이 처음 보는 문항만 쓴다.
- 적응형 진단은 앱 안 ‘첫 수준 확인’에 연결되어 있으며, 독립 시연 화면 `diagnostic.html`도 제공한다.
